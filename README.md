# 映川 v0.2.5 · 个人影视播放器

Mac原生应用：检索网络影视目录、选择集数、在软件内播放，并在播放过程中使用GPU增强画面。源码与实际应用都在本目录。

## 启动

双击 `dist/映川.app`。当前安装包面向 Apple Silicon Mac，为本地签名版本。已运行旧版时先退出再打开新版。首页兼顾电影、国产剧和美剧，提供推荐关键词和近期搜索。点击作品，选择来源、线路和集数开始播放。也可以搜索其他作品，或从左下角导入影片/媒体链接。

左侧导航及底部打开入口支持整行点击，当前页面高亮显示，鼠标经过或按下时提供反馈。切换到待看、继续观看等页面再回到探索，会保留本次搜索、筛选与已加载结果；需要重新发现时可清空搜索框后搜索，或在媒体来源页选择“刷新发现页”。侧栏改动验证见[v0.2.5验收记录](docs/验收记录-v0.2.5.md)。

- 播放：单击影片画面即可暂停/继续，双击只切换全屏；单击会等待系统双击间隔，避免双击时先暂停。拖动、点控件、右键、切集或失焦会取消尚未执行的画面单击。播放/暂停与快进快退按钮扩大为36×36点击区域；连续操作按最新播放意图与累计跳转目标处理。也可用空格暂停/继续，左右键前后10秒，上下键音量，F全屏，M静音；支持进度拖动、倍速、选集和下一集。音量、静音前音量、倍速、画质模式和自动连播偏好在本机保存；可选择15/30/60/90分钟后暂停。
- 进度预览：鼠标停在进度条上，显示对应时间的画面缩略图；拖动时也可预览，松开后跳转。预览使用独立解码器，不改变主播放进度和声音。网络位置首次取帧可能需要等待，失败时明确显示暂不可用；不会展示上一位置的旧图。预览显示原始画面，不叠加外部字幕或广告柔化。
- 全屏：F、双击画面或全屏按钮进入沉浸模式，选集侧栏与播放诊断不再占据画面。播放中约3秒无操作后淡出顶部与底部控制栏，并隐藏鼠标；移动鼠标或按键即可显示。鼠标停在控件区、拖动滑块、打开菜单、暂停、缓冲或报错时保持可见。Esc/F或退出按钮回到窗口模式，恢复原选集布局。字幕独立显示。
- 广告柔化：播放控制栏的“广告柔化”→“框选广告与字幕保护区”。视频暂停后，在真实画面里拖出广告矩形；绿色底部28%默认保护，可切换“保护字幕”额外框出顶部、中部或双语字幕。黄色为广告框，重叠保护区的框会被拒绝；新增保护区后若已有广告框变红，应先移除冲突框。点击“应用柔化”，支持最多6个广告框和6个附加保护框。可随时关闭显示原画面；换集、换源或重新打开影片时清空，重试同一影片保留。只是局部模糊，不是无痕删除或背景重建，也不自动识别广告。
- 字幕：播放控制区的字幕按钮可选择已有轨道，或导入UTF-8 SRT/VTT/ASS文本；外部字幕可调整时间。ASS文本会提取对白，不支持完整ASS样式/动画。
- 画质：播放页右下角切换“原片”“GPU清晰增强”“GPU增强至4K”“Apple AI超分”；显示实际源尺寸、输出尺寸和回退原因。
- 来源：内置电影天堂、非凡、如意、魔都、无尽共5个目录；可启停、检查目录连接及代表影片媒体、添加兼容HTTPS CMS JSON接口。打开聚合作品默认优先魔都，可在“媒体来源”修改优先来源；手动来源筛选与详情选择优先，停用/移除后不会继续自动选用。升级会补入新增内置来源，同时保留已停用或移除的旧来源。单次检索最多使用列表中的前24个启用来源；目录在线不代表每部影片可播放。
- 找片：同名同年份作品聚合为一个入口，在详情选择来源版本；保留不同年份、不同季的独立条目。支持来源/年份筛选、排序、逐来源加载更多，以及单来源分类目录浏览。
- 待看：海报或详情点收藏，加入“我的待看”，重启后保留；移除待看不影响历史。
- 换源：播放页打开右侧“选集”，点击“查找其他片源”，再选择显示来源名与季标题的候选。程序核对同季同集、检查媒体清单后在软件内切换，并在资源就绪后恢复进度。版本时长或剪辑可能不同，恢复位置受新时长限制，需核对画面并按需拖动；候选画质显示为未知，实际画质看播放信息。季数不明确、集名或编号不匹配时保留当前播放。
- 历史：默认展示每部作品最近一集，也可查看全部记录、单条移除；详情可直接续播，关闭再打开保留上下文。进度跟随实际来源版本，跨版本不会自动混用。
- 故障处理：失败后重试保留外部字幕与偏移，普通暂停时重试维持暂停；无效字幕作为独立提示显示，播放器仍可继续使用。可从播放错误处重新寻找其他来源。

## 大陆网络与媒体连接

本轮把“目录在线”和“影片数据可读取”分开检测。来源页点击“检测媒体”会读取代表片名、同名详情、实际HLS和首分片前缀，显示阶段、样本、时间及失败原因；支持最多3个检查任务、排队和取消。结果仅保留在本次会话。手动媒体检查也可用于停用的来源，“检测全部媒体”仅检查已启用来源。

应用内检测会单独排除HTTP/HTTPS/SOCKS/PAC代理，但VPN路由、系统DNS仍可能影响结果。正常检索和播放仍遵循系统网络设置。页面会显示代理/隧道迹象，不能把HTTP代理排除或一次成功标为大陆免VPN认证。

2026-09-27另用物理网卡绑定+独立AliDNS解析进行了开发期探测，未修改系统设置：电影天堂、魔都的《怪奇物语第一季》样本通过搜索、详情、HLS和两段前缀读取；非凡详情超时、如意TLS错误、无尽搜索超时。公开大陆节点另测魔都该片子清单有258/270个HTTP 200，首分片有261/270个HTTP 200或206响应，三大运营商均有成功样本。因此默认优先尝试魔都，但既有来源仍可选择，不因一次失败自动停用。

这些是指定时间和指定影片的连接样本，未证明全国所有网络、所有剧集或整集持续播放。本机物理接口的出口所在地未独立核验。完整方法与数据见[大陆连接调研](docs/research/mainland-connectivity.md)和[物理接口样本报告](docs/validation/v0.2.2/direct-media-physical.md)。

## 画质模式的含义

| 模式 | 实际处理 |
| --- | --- |
| 原片 | 系统解码与原始画面 |
| GPU清晰增强 | Core Image/Metal去噪及温和锐化，保持源尺寸 |
| GPU增强至4K | 去噪、Lanczos等比例放大、锐化，实际生成最高UHD尺寸的画面；这是GPU修复/缩放，不是AI超分，也不证明原生4K细节 |
| Apple AI超分 | VideoToolbox实际神经网络处理，按设备和输入尺寸查询可用倍率；本机M4已测试720p×1.5到1080p，不支持的1080p输入会显示原因并回到原片 |

增强在播放中进行，不需要等待整集处理完，也不生成整集帧文件。软字幕最后绘制。默认流畅优先，持续超过帧预算或遇到未支持的HDR处理时明确回到原片。能处理4K像素不代表屏幕具备4K物理分辨率，也不代表还原了丢失细节。

## 构建和测试

开发机需要macOS15+和Swift工具链；Apple AI需要macOS26+及运行时能力支持。项目没有第三方包依赖。

```bash
bash scripts/swift.sh test
bash scripts/build-app.sh release
```

`scripts/swift.sh`会在`.build`中准备匹配的SwiftPM公开接口，解决此开发机CLT中残留的旧版private接口；不会修改系统工具链。最终.app只依赖macOS系统框架，不需要用户安装Python、FFmpeg或其他播放器。FFmpeg仅用于开发期媒体核验。

各版本的验证范围见验收记录；核心测试、GPU合成帧比较、原生窗口交互和完整影片观看分别记录。

诊断命令（运行播放测试时静音）：

```bash
dist/映川.app/Contents/MacOS/Cinema --benchmark
dist/映川.app/Contents/MacOS/Cinema --validate --seconds 1800 --title 怪奇物语 --mode upscale4K --report docs/validation/playback-report.json
```

首条处理合成帧，不能替代网络播放验证。第二条实际检索、内嵌播放并记录AVPlayer/GPU指标；不会完整验证剧情身份或主观画质。

- v0.2新增如意、魔都、无尽：分类浏览与第2页、搜索第2页均经过实际服务核验；12个电影/国产剧/美剧/动画短样本中10个通过2秒解码，其余失败细节保留。见[来源扩充报告](docs/validation/v0.2/source-expansion.md)。这不代表完整观看、全站稳定或所有作品唯一可用。
- v0.1的电影天堂目录（dytt）和非凡目录（ffzy）保留。前者完成三剧164集基础清单检查及每季首、中、末集共45个短解码样本，后者已核验三剧目录、详情及部分媒体样本；两个目录不代表独立基础设施，也不代表两边所有剧集均已完整观看。证据见[主来源报告](docs/validation/source-report.json)、[代表样本报告](docs/validation/representative-decode.json)和[备用来源报告](docs/validation/backup-source-probe.json)。
- 该目录随时可能变化；影片供应许可未核验。官方平台网页不是通用媒体链接，本程序不登录会员账号、不提取浏览器凭证或绕过DRM。
- 核心播放采用AVFoundation。HLS、MP4等是否可播取决于实际编码；尚未集成libmpv，不能承诺MKV、所有音频编码和全格式字幕。
- 没有验证到三剧的原生4K来源；目前GPU4K路径可以改善显示效果，不能称为原生4K或AI4K。
- HDR增强、多设备同步、完整ASS排版和通用1080p→4K AI模型尚未实现。
