# 播放页视觉改版 · v0.3

## 目标

让视频画面成为窗口和全屏的主视觉。常用动作一眼可见、点击区域一致；画质、广告处理和诊断仍可找到，但不常驻画面。保留已实现的画面单击播放/暂停、双击全屏、自动隐藏、悬停预览、字幕避让、选集与撤销跳过。

## 页面层级

1. 视频铺满播放器区域。顶部以渐变承托返回、片名/集名、视听适配与选集入口；普通窗口和全屏共用一套布局，全屏不显示侧栏。
2. 底部以渐变承托进度条和单排操作：强调播放/暂停，紧邻快退/快进与下一集，时间可点击精确跳转；右侧放速度、字幕、画质、音量、更多及全屏。图标按钮约 42–46 点，提供悬停与按下反馈。
3. 跳过广告与字幕提示出现在顶部轻量通知中，保留撤销/关闭动作。帧尺寸、处理耗时、色彩回退原因等仅在播放信息或设置菜单中查看。
4. 选集侧栏默认折叠，打开后清晰区分当前节目、线路、剧集、自动连播和替换片源；全屏始终隐藏。

## 行为边界与验收

- 沿用 `PlayerPresentationController` 的自动隐藏与菜单交互计时；不重写视频输入层和 `SeekBar` 预览解码。
- 播放/暂停、快进/快退、拖动、字幕、音量、画质、跳广告、柔化、选集、返回与全屏仍调用原有模型动作。
- 在隔离的原生 QA 应用中检查普通窗口、窄窗口、全屏、自动隐藏、预览、字幕和跳过撤销；跑核心与控制交互回归，再构建新版本应用。
