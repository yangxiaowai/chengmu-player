# v0.3.1 统一入口与自然画质

用户目标：整合旧版功能与新版播放界面，参考成熟 GitHub 播放器改进体验，并解决增强后噪点更多的问题。

v0.3.0 直接继承 v0.2.9，媒体、历史、字幕、广告、HDR/杜比功能已整合。发布入口统一为 `dist/映川.app`，保留 `local.yingchuan.cinema` 身份和所有用户数据路径；旧 bundle 转入历史版本备份，不并行启动。

画质以忠实原片和噪声不被放大为先。用固定随机种子的暗场、中灰和彩色噪声、硬边字幕和细纹样本量化 RMS 误差、亮度漂移、过冲及边缘保留；保留旧算法基线图。移除叠加锐化，降噪与无过冲缩放分开，4K 明确是缩放。HDR/杜比继续原生呈现，原片保持可选。新安装默认原片，已有明确画质偏好保留并应用改进后的算法。

交互借鉴 IINA/mpv 的滤镜切换与实际状态反馈，独立实现，不引入新的播放器依赖。播放页与画质工作室使用同一选择方法；原片对照是临时状态，不修改持久偏好、播放位置、音轨或字幕，换片时退出对照。菜单分别显示所选处理与实际呈现，增强尚未出帧或回退时不显示已经增强。

保留 v0.3 播放布局、全屏隐藏选集和自动隐藏策略。1040 点宽展开选集时，新增对照入口必须仍能放入控制栏；优先压缩非必要文本与音量滑块，不缩小主要播放目标。
