# v0.3.3 实时画质与加载诊断

用户希望充分使用本机计算资源，通过算法与实现优化让更高清画面在观看时处理；同时报告影视加载失败。保留流式、字幕、原片对照、HDR原生、已有用户数据与网络设置。

## 实测驱动的两条路线

1. **模型精确优化实验**：固定输入/FP16/compute units，查询Core ML算子设备计划；ECA Conv1D→Conv2D、Toeplitz通道卷积、52→64补零。输出须与原模型数值一致。计算计划是估计，不能冒充实测GPU利用率。仅凭微小计时波动不宣称加速。
2. **轻量混合管线**：维持当前帧＋过去一帧的原生时域降噪，系统AI支持时先用其真实倍率；不足4K的输出再用自编Metal shader做细节保护缩放。插值内核为经典Catmull–Rom，局部对比度与4×4梯度方向一致性控制其相对双线性插值的权重，最近2×2范围限制负瓣过冲。不额外锐化。此为工程组合与实现优化，不宣称原创学术算法或AI恢复原生4K细节。

## 内存与时序

Metal将源帧一次写入linear RGBA16F；插值、局部限幅、sRGB编码一次compute pass写入最终BGRA8纹理，避免额外4K中间纹理与CI回写。源纹理只在串行worker复用，最终纹理每帧独立持有，不覆盖正在显示的帧。command完成后才发布耗时/结果。HDR门禁、单帧在途、音频时钟、迟帧丢弃和超预算回退保留。

## 验证门槛

先独立原型，再检查颜色/上下方向、字幕阶跃无过冲、边缘相对B-spline变窄、平坦区不明显放大噪声；1080→4K完成时间、真实样本统一显示尺度比较。只有通过后才接入“流式修复”。不保证在每个PSNR指标或每部影片上获胜，清晰片源仍可原片对照。
