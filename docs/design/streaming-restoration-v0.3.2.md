# v0.3.2 流式画质修复设计

用户确认噪点、压缩痕迹、模糊和运动观感都需改善；坚持 Mac 边看边处理。首先验证真实方法、性能、失真，再加入应用。新档位不自动覆盖已有用户选择。

## 调研结论与取舍

详见 `docs/research/restoration-papers-2026-09-28.md` 和 Mac 实测记录。覆盖 12 种论文/开源方法。EfRLFN 面向压缩流媒体，但 M4 上固定 720p Core ML FP16 每帧约 105 ms，不能承担实时 24 fps；保留可复现转换、画质、性能实验，暂不放进播放管线。大型扩散模型及需要未来帧/双向传播的网络不作为当前流式默认。

采用 macOS 26 VideoToolbox 原生时域降噪：当前帧和前一原始帧，无未来帧、无额外解码器。16-bit float RGB 转 lossless 10-bit YUV，完成回调后才交付。新“时域降噪”保留尺寸；新“流式修复”先时域降噪，再按系统实际支持倍率运行现有 Apple 超分，不支持倍率时保留时域结果并明示状态。禁止把插值或仅选择档位称为真实 4K 修复。

## 边界

- HDR、杜比视界、未知色彩、受保护媒体继续系统呈现；不重新标记成 SDR。
- source/seek revision、非递增 PTS、间隔超过 150 ms、尺寸/模式变化、切镜会重建历史。首帧返回当前原图并显示正在建立参考。前帧不得使用上次修复结果，防止递归拖影。
- 不叠加额外锐化或全局涂抹。字幕由运动/切镜及专门换字夹具验证；画内字幕无法保证在所有降质输入上完全不变。外挂字幕仍由独立叠层展示。
- 保持单帧在途、音频时钟、超时丢帧、连续超预算回原片。任何核验数据限定为本机/样本，不替代长片或所有源验收。
- 广告识别复用当前解码帧；局部柔化在修复完成后独立作用，字幕保护/框外像素保证保留。
