# 澄幕 v0.3.7

原“映川”更名为“澄幕”。本次发布保留原应用标识和 Mac 上已有的观看历史、偏好；使用仓库构建脚本安装时会归档旧应用。直接解压附件安装时，可自行移除旧的“映川”应用入口。

Mac 原生播放器目前支持影视目录检索、本地影片和直连媒体导入、选集、进度预览、原片对照、SDR 流式修复，以及片源允许时的杜比/HDR 原生呈现。v0.3.6 增加的“压缩抑噪”仍为可选实验档：短片对照没有证明普遍更清晰；本机 1080p60 也未验证为稳定实时。

附件 `澄幕-v0.3.7.zip` 包含 Apple Silicon 的 `.app`，版本 **0.3.7 / build 19**，采用本地签名，尚未经过 Apple 公证。解压后可将应用移入“应用程序”。从旧版升级时，应用的内部标识不变。

本地发布检查：160 项核心测试通过；Release 编译、应用签名、ZIP CRC、解压签名、可执行文件和版本信息核验通过。详细边界见[验收记录](../验收记录-v0.3.7.md)与[发布清单](../validation/v0.3.7/release-manifest.json)。
