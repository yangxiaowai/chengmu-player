# 澄幕 v0.3.8

修复播放期间屏幕因系统空闲计时自动变暗、休眠的问题。

- 默认启用“播放时保持屏幕常亮”，在播放界面“更多播放设置”中可关闭，选择会保存。
- 原片与增强画面共用系统保活；准备、短缓冲和拖动期间保持，暂停、结束、播放失败时释放。
- 停止后的延迟回调不会重新申请；应用退出主动暂停并释放，对象析构也负责清理。
- 系统拒绝保活或释放请求时，在菜单显示原因。

本机通过161项核心测试，以及真实AVPlayer和系统电源请求的专项检查、已有播放稳定性回归。专项证明系统已登记/清除请求，没有修改显示器休眠超时，也未进行长时间实际屏幕亮度观察。参考 IINA、mpv 的生命周期做法，详见[调研与验收边界](../research/display-sleep-2026-10-26.md)。

附件 `Chengmu-v0.3.8-macOS-AppleSilicon.zip` 为 Apple Silicon 版，版本0.3.8/build20，本地签名，尚未经过Apple公证。
