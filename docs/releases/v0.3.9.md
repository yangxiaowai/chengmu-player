# 澄幕 v0.3.9

- 连续快进/快退按短窗口合并，累计目标立即显示；长按可持续定位，绝对跳转和换片可取消旧请求。
- 修复暂停后传输失败通知导致自动重播，并补齐延迟跳转与真实片尾、广告跳过之间的状态处理。
- 新增“轻度流式修复”，在画质设置中可切换轻度/常规强度，保留原片对照。

同一短片三种退化、每种96帧的生产输出对照仅有小幅收益（PSNR约+0.018～0.044dB）；强噪源仍可能更适合常规档。新档为可选，不代表所有影片更清晰或达到原生4K/稳定60fps。

验证：核心162项、播放稳定性21项、系统保活19项、流式处理57项、短时真实AVPlayer播放31项通过。详细证据与范围见[验收记录](https://github.com/yangxiaowai/chengmu-player/blob/v0.3.9/docs/验收记录-v0.3.9.md)。
