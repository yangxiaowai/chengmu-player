# 澄幕 v0.4.0

- 重设计探索、搜索、影片详情、待看、历史、来源管理、画质设置及播放控制，统一为深色观影界面与蓝色操作。
- 移除日常界面中的“抽样”“首集参数”“轨道读取”等检查用语。封面与内容优先，详细连接和处理信息可展开查看。
- 自动读取可见作品的媒体分辨率，详情比较来源/线路的分辨率与帧率；新增清晰度排序、手动更新和自动识别开关。卡片始终显示画质或识别状态，读取失败后继续尝试同作品的后续来源；右键“更新画质”可优先重试。
- 播放与性能检测时停止后台识别；限制并发与排队，合并相同媒体请求，并缓存成功与失败结果。手动更新优先处理。

显示的是指定来源某一集的媒体参数，不保证整季一致，也不代表主观清晰度、所有 HLS 码率版本、整集稳定播放或大陆免 VPN 认证。原有修复算法保留，本版不宣称新增 4K/60 帧或杜比能力。

界面参考 B 站官方网页与 Mac 宣传展示图，没有取得或复制其客户端源码。详细测试与限制见[验收记录](https://github.com/yangxiaowai/chengmu-player/blob/v0.4.0/docs/验收记录-v0.4.0.md)。

附件 `Chengmu-v0.4.0-macOS-AppleSilicon.zip` 为 Apple Silicon 版，0.4.0/build23，本地签名，尚未 Apple 公证。
