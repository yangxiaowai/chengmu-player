# 澄幕 v0.4.1

- 找片更准确：相关性排序优先匹配片名与季数，新增影片与剧集、解说、预告、短剧分类，与来源、年份组合筛选；支持一键重置。未分类影片保留，减少误隐藏。
- 字幕更易用：S 或 ⇧⌘S 隐藏/恢复，不丢失当前字幕选择与偏移。新增字号、背景、上移设置并记住选择；暂停时导入字幕立即显示，同片重试保留字幕，新片清除旧外挂与时间偏移。
- 继续观看默认显示未看完，可切换全部记录或全部剧集；已看完标记与重新观看入口不删除历史。修复组合筛选后部分待看标记丢失、重复收藏的问题。
- 保持既有画质标识、流式修复、HDR原生路由与屏幕常亮策略；日常播放菜单收起广告分析帧数等内部信息。

本轮参考 IINA、mpv、Swiftfin、Stremio 的公开文档/议题及可公开读取的社区原帖。小红书、X、Instagram 本次需要登录，未取得可引用帖子，未将其冒充已完成的需求调查。见[调研](https://github.com/yangxiaowai/chengmu-player/blob/v0.4.1/docs/research/player-social-feedback-2026-10-26.md)。

180项核心测试通过，字幕控制器21项、模型/渲染20项、播放稳定性21项、控制栏12项、屏幕常亮19项回归通过；另核对实际字幕快捷键、全屏和已安装版分类菜单。测试使用本地媒体与可控数据，不代表所有网络片源或整集播放认证。范围见[记录](https://github.com/yangxiaowai/chengmu-player/blob/v0.4.1/docs/验收记录-v0.4.1.md)。

附件 `Chengmu-v0.4.1-macOS-AppleSilicon.zip` 为 Apple Silicon 版，0.4.1/build24，本地签名，尚未 Apple 公证。本版不宣称新增4K60、杜比认证或修复算法效果提升。
