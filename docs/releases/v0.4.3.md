# 澄幕 v0.4.3 · 选源先看响应

- 影片详情的播放来源和线路同时显示画质与“响应 N ms”，支持“更新画质与延时”。播放页的线路菜单、所选线路及其他片源列表也展示已有结果。
- 明确显示等待、检测中、响应超时或暂未获取。测速失败不影响画质读取和正常选源；没有画质时仍保留有效的HTTP响应结果。
- 相同媒体地址共用检测和15分钟会话缓存，限制为原有最多2个任务；手动更新可重测。播放或性能检测开始后取消后台任务，缓存仍可查看。

响应时间来自当前网络对具体媒体地址的HTTP HEAD请求，包含本次连接等开销，不下载影片正文；不是Ping、起播速度、带宽、整集稳定性或大陆免VPN认证。同线路不同集数可能不同。部分来源拒绝HEAD时显示未获取，仍可正常尝试播放。

核心191项/25套件、真实本地HTTP12项、新响应队列17项、原画质队列23项、新界面8项、原界面18项及播放稳定性21项通过。详见[验证记录](https://github.com/yangxiaowai/chengmu-player/blob/v0.4.3/docs/验收记录-v0.4.3.md)。
