# 澄幕 v0.4.5 · 更多来源，更从容地选择

- 详情页自动查找来源，根据已读取的分辨率和 HTTP 响应优先展示五项；可展开并继续查找，未知项保留。每条来源都能单独更新画质和响应信息。
- 增加 Internet Archive 开放影片及 Wikimedia Commons 开放短视频目录，展示来源和许可说明。目录结果不保证版权、播放、地区可用性或包含商业影视。
- 同名不同年份、明确的电影与剧集及开放短视频会谨慎分组；播放中的电影换源也会核对名称、年份和详情。
- 无参数、无凭据且无共享 Cookie 的普通 HTTP(S) MP4/MOV/M4V 文件尝试排除 HTTP/SOCKS 代理，失败时回退系统网络；HLS、签名及受保护资源仍使用系统网络。VPN、DNS 和实际地区路由不由此功能控制。
- 参考 IINA、mpv 和 VLC 的缓冲、预览与任务回收思路，优化已识别的无后缀 HLS 悬停预览，以及播放器等待时的日志读取。

画质与响应排序仅覆盖当前找到和测量到的候选；响应值为系统网络下对媒体地址的 HEAD 时间，不是起播时间或全网排名。[参考资料](https://github.com/yangxiaowai/chengmu-player/blob/v0.4.5/docs/research/opensource-playback-review.md) · [验证记录](https://github.com/yangxiaowai/chengmu-player/blob/v0.4.5/docs/验收记录-v0.4.5.md)
