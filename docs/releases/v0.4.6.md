# 澄幕 v0.4.6 · 更快发现，接着上次观看

- 搜索时，已完成的来源结果会陆续显示，无需等待所有来源；进入播放会中断尚未完成的片库查找，返回后可选择继续寻找或重新加载片库。
- 画质读取与媒体响应检测并行开展，减少两项任务串行等待；检测失败或缺少数据时仍会显示相应的未知状态。
- 播放页按当前集显示已获取的线路响应信息。其他线路只有在集数与名称能够匹配时才使用对应结果，缺失或有歧义时不会猜测；播放期间不为此额外启动后台检测。
- 剧集详情的“继续观看”在当前集看完后接续可确认的下一集，恢复该集已有的观看进度；已确认的整部剧集看完后可从第一集重新观看。集数缺失或无法确定时会提示手动选择。观看历史的分组也更谨慎，避免同名电影、剧集和短视频互相遮挡。

来源推荐和响应信息只覆盖当前找到、已测量的候选。响应值是对媒体地址的 HTTP HEAD 测量，并不等同于起播时间、持续播放速度或全网排名；实际可用性取决于来源和网络。

此前针对符合条件的普通网络视频文件的代理排除与回退保持可用。HLS 直连仍处于独立可行性研究阶段，**未接入本版播放器**；HLS 播放仍遵循系统网络设置，不保证大陆网络可达。详见 [HLS 研究记录](../research/hls-direct-feasibility.md)及[本版验证记录](../验收记录-v0.4.6.md)。
