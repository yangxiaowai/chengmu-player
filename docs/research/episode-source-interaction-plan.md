# 选集与换源交互小步优化

本轮范围由主代理确认：只修改 AppModel，新建 PlayerEpisodePanel；主代理负责 PlayerView 接入。保持现有来源和严格同季同集判断，不改变手动选集默认开始播放的行为。

1. 先用独立 swiftc + 本地静音 WAV 复现暂停后切线路自动播放；报告记录 red，再做实现。
2. 选集面板使用 ScrollViewReader，在显示面板和当前集变化时定位当前集，保留用户手动滚动；增加相邻上一集/下一集按钮。模型统一检查当前记录身份、线路、集目及数字连续性，首尾/缺集不可越过。
3. 换源区分搜索、读取详情、核对当前线路三个阶段；显示正在检查的来源和线路。用户取消保留已找到候选及当前播放，取消任务并更换 token，任何迟到结果不能切换媒体。
4. 切线路、提交换源时同步读取最后的 playbackRequested；现有 play 完成后若原意图是暂停则立即 pause，不覆盖异步核对期间的新意图。
5. 回归覆盖真实播放器暂停/进度、相邻集和缺集、取消期间迟到搜索/详情/清单、新选择替换旧任务、同季同集拒绝。网络依赖用明确注入的异步 fixture；不操作用户 UI，不跑全套 SwiftPM。主代理完成 native UI 与整合构建。
