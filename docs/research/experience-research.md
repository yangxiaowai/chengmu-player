# 个人影视播放器：体验研究与 V1 验收建议

调研日期：2026-09-27（Asia/Shanghai）。资料范围：公开官方帮助、产品活动页及项目文档。没有登录或体验任何平台账号功能，没有验证其内部实现，没有编写产品代码。以下“可确认事实”和“本项目建议”明确分开；官方帮助可能随版本改变。

## 1. 已确认方向与产品目标

用户确认：Mac 桌面优先；自动检索公开可播放来源，同时允许导入网络链接和本地视频；先寻找已有高清资源，再在本机流式增强，边看边处理。最新要求取代先前等待离线处理完成的主流程。常看《怪奇物语》（Stranger Things）、《绝命毒师》（Breaking Bad）、《火线》（The Wire），这三部商业美剧是必须在软件内观看的内容验收对象。

核心任务是“找到我能播放的版本，安心看完，下一次接着看”。首页、选集、继续观看、字幕音轨和播放故障处理服务于这个任务。V1 不承诺覆盖全网影视，尤其不能承诺热门商业电影/剧集均存在合法公开直链。搜到电影条目、简介或海报，只能说明元数据匹配成功。

## 3. 来源与元数据必须分层

建议在产品文案上区分三个状态：

1. **影视条目**：有标题、年份、简介、海报等元数据；没有播放保证。
2. **来源候选**：发现公开页面或用户导入链接；尚未确认媒体可达或可由当前播放器播放。
3. **已验证可播放**：本次检查成功，记录来源、检查时间、媒体类型、实际技术信息；链接过期后可降回待验证状态。

自动检索的 V1 范围应采用明确来源白名单，以公开授权、公共领域或用户有权使用的资源为起点。平台页面、预告片、花絮和正片必须有类型区别；仅可在官方网站观看的作品应显示“打开官方页面”，不要伪装成应用内可播放。受登录/会员/DRM约束的商业平台不作为默认直链提供者；无需读取用户浏览器Cookie或承诺破解平台保护。公开不等于无版权。

同片多版本显示来源、分辨率、编码、帧率、HDR状态、字幕/音轨和是否可离线；未知字段明确为未知。优先寻找更好的原始资源，不把增强后的1080P标成原生4K。

TMDB API 提供电影/电视剧/演员的数据和图片，不提供正片。其官方 FAQ 说明非商业使用需署名，商业用途需联系授权，服务没有 SLA。在“关于/致谢”中使用获准标志与指定声明：

> This product uses the TMDB API but is not endorsed or certified by TMDB.

使用前仍应检查最新条款。[TMDB官方FAQ](https://developer.themoviedb.org/docs/faq)

## 4. V1需求与建议验收标准（尚未实现）

下表是补充研究建议，尚未冻结为项目规范，也不是已完成测试结果。性能数字须在架构阶段固定样本、存储介质、显示器、系统版本和播放器后再冻结。三部用户指定美剧用于内容来源验收；Blender开放短片等技术样本只能验证解码、4K或增强链路，不能替代三剧证明来源需求已满足。

| ID/优先级 | 需求 | 可验收结果 |
| --- | --- | --- |
| R01/P0 | Mac桌面观影 | 能安装/启动；打开本地文件和公开测试链接；关闭重开后个人库与偏好保留。明确受支持macOS版本与芯片。 |
| R02/P0 | 导入本地资源 | 文件选择、拖入文件、添加文件夹；MP4/MKV等承诺格式有测试清单。失败显示具体文件；重复扫描不增加重复版本，不修改/删除原文件。移动文件后可重新定位。 |
| R03/P0 | 导入网络链接 | 可输入直链；公开页面与直链区分；可达性、格式不支持、403/404、过期分别提示。不得在日志显示带令牌的完整链接。 |
| R04/P0 | 自动检索公开来源 | 固定来源白名单；按片名/年份检索。针对《怪奇物语》《绝命毒师》《火线》逐剧记录条目匹配、正片来源发现、实际播放验证、季集覆盖与最高可用画质；无来源显示“暂无可播放来源”。预告、片段、平台入口、海报结果均不计入内置正片播放成功。 |
| R05/P0 | 统一影视库与首页 | 首页建议为继续观看、最近添加、待看；筛选电影/剧集及来源。空库可直接导入；内容已缓存时断网仍可浏览本地库，不强制登录。收藏/待看和继续观看可移除。 |
| R06/P0 | 详情、季集、资源版本 | 按季/集数排序；可纠正片名/年份/季集；显示缺失集；同集多资源可选择。打开不可用版本时不静默切到另一个来源。 |
| R07/P0 | 播放与键盘 | 播放/暂停、10秒快进后退、拖动、音量、静音、全屏；空格、左右、上下、M、F、Esc有帮助提示。搜索输入框内按键不会误控播放；未知时长/不可seek的流明确显示限制。 |
| R08/P0 | 继续观看 | 按作品/具体集保存位置；正常退出重启后续播误差≤2秒，异常退出损失目标≤10秒。提供从头播放、标记已看、移除历史；集数与资源版本发生变化不错误续播。完成判定阈值作为可配置规则。 |
| R09/P0 | 字幕与音轨 | 内嵌轨道和外部SRT至少作为基线；列出语言/名称，能关闭字幕和切换音轨。中文字幕无乱码；字幕时间偏移可调，偏好跨重启保留；没有对应轨道时显示真实情况。ASS/PGS等是否必需待样本确认。 |
| R10/P0 | 4K事实展示 | 基线测试覆盖真实3840×2160的H.264与HEVC样本；至少连续30分钟、seek10次、暂停恢复、字幕开启，记录丢帧/音画同步/内存。目标丢帧<1%、音画偏差≤100ms、无崩溃；未满足则不能宣称该组合通过。4K源在低分屏播放只标源分辨率。 |
| R11/P0 | 网络失败恢复 | 区分正在打开/缓冲/暂停/出错；断网和限速有可取消重试及恢复位置。有低码率版本时用户可切换；单一版本不显示虚假的画质档位。不用无限转圈掩盖权限或失效。 |
| R12/P1 | 连续追剧 | 有明确下一集时片尾显示倒计时并可取消；自动续播可关闭。缺集、季终、失效来源停下并说明，不自动跳过未看的缺失集。 |
| R13/P1 | 元数据与海报 | TMDB等为可选；无密钥/断网仍可用文件名与本地封面；误匹配可人工更正；展示来源与署名。未联网不阻断已导入内容播放。 |
| R14/P0方向已确认，细则待冻结 | 高清优先与流式增强 | 用户要求边看边处理，不等待整集完成；先展示可验证的更高清原始版本。播放中可开关/A-B比较，保持音画与字幕同步，显示源尺寸、增强尺寸和真实模式；有界队列，拖动清除旧帧。处理过载时降低强度或暂停等待的偏好尚待答复。每个宣称支持的组合需至少30分钟持续测试；普通放大不标成AI超分。 |
| R15/P1 | 隐私和诊断 | 历史默认本机保存，可清除；扫描范围由用户指定。故障报告可查看并手动导出，默认去除用户名路径、密钥与URL令牌。 |

“4K优先”应先实现分辨率和兼容性正确展示，再验证目标机真实样本。HDR、杜比视界、音频直通、多声道、4K60与4K120是不同能力，不包含在“4K能播放”的默认承诺内。流式增强质量与持续吞吐必须实际测试，不能从模型介绍或短片速度直接推断用户M4/16GB可实时4K增强。

## 5. 后续严格按需求 → 架构 → 实现推进

**需求冻结前**落实用户后来明确的硬要求：三部指定美剧必须在软件内直接看，平台跳转不算交付；先核查来源可行性再定范围。主代理已补充网络目录与三个短样本解码记录，见[综合需求评审](../需求与可行性评审.md)，尚不构成完整剧集或应用内播放验收。4K优先与本机流式增强方向已确认，过载处理偏好尚待答复。

**架构阶段**才选择播放器内核、桌面框架、来源适配方式、缓存与媒体库模型、增强任务方案。用最小技术试验验证关键样本和许可证；技术验证不等于交付完整产品。

**实现阶段**按P0链路验收：导入/查找 → 选择真实资源 → 播放与字幕 → 流式增强及过载处理 → 记录进度 → 重开续播 → 故障恢复；再做P1。首页视觉可以借鉴成熟平台的聚焦观影习惯，但应避免在可播放资源不足时用大规模海报列表制造“片库齐全”的错觉。

## 6. 建议边界与当前待确认项

V1建议排除会员平台登录集成、DRM绕过、社交评论/弹幕、直播、远程多用户服务器、跨设备云同步、广告推荐与复杂推荐模型。是否恢复其中某项应另做需求和验收，不默认为用户要求。

当前已确认：不接受用平台跳转替代三部指定美剧的软件内观看。首版功能和完整验收口径待用户审阅[综合需求评审](../需求与可行性评审.md)。

后续进阶项可在架构验证或使用真实样本时确定，无需本轮逐一询问：HDR/杜比视界、多声道、目标显示器、ASS/PGS字幕、增强缓存预算与可选导出格式、NAS/Jellyfin库和跨设备需求。它们不撤回已确认的Mac、本地/网络、4K优先与流式增强方向。
