日期：2026-09-27。范围为公开官方资料、少量公开 API 只读请求；未登录平台、未读取浏览器凭据、未下载电影、未验证完整播放。此文件是需求阶段的研究证据，不是影视来源覆盖承诺。

后续更新：用户已明确三剧必须软件内观看，平台跳转不满足需求。主代理随后读取了三剧的公开聚合目录、首集清单和各一个媒体分片，在内存中完成2秒解码；完整结果与未测范围见[综合需求评审](../需求与可行性评审.md)及[探测记录](network-source-probe.json)。以下官方页面和开放影片研究不代替这份最新技术证据。

## 2. 三种能力应分别交付

1. **作品发现**：识别片名、别名、年份、季集、海报。
2. **来源发现**：找到同一作品/同一集的资源候选、所在平台或用户已有文件。
3. **真实播放**：取得当前可用的媒体资源，实际成功解码并播放音视频。HTTP 成功、能读元数据、能出首帧和能稳定看完是不同证据层级。

TMDB 的 [Watch Providers 文档](https://developer.themoviedb.org/reference/movie-watch-providers)明确只提供按地区的流媒体/租赁/购买渠道信息，连完整深链都不是默认结果，更不是正片视频流；使用这些数据还须标注 JustWatch。TMDB 如作为海报/季集数据源是可选服务，不应成为本地视频播放的前置条件。

## 3. 可执行的来源接入候选

| 候选 | 合理定位 | 限制与进入 V1 的条件 |
| --- | --- | --- |
| 用户导入本地文件、文件夹 | 稳定的个人片库入口 | 实测容器、编码、字幕、音轨；移动文件可重新定位 |
| 用户导入 HTTP(S) MP4/HLS/DASH 等资源 | 直接播放已取得的资源 | 需区分网页与媒体、处理过期/403/404/断网；格式后缀不代表可解码或无 DRM |
| Internet Archive | 公开资源检索候选，适合部分开放影片/历史影像 | 按条目核验内容身份、来源和使用许可；公开上传不等于统一授权，也不承诺热门剧集覆盖 |
| Blender 开放电影官方来源 | 清晰度比较和播放测试资产；可做少量精选内容 | 不作为完整影视库替代；下载包可能是 ZIP，不能直接传给播放内核 |
| 官方商业平台入口 | 作品资料与发行信息 | 用户已拒绝以平台跳转替代内嵌播放；这类资料不能计作三剧播放完成 |
| 按网站开发的公开页面解析器 | 后续按需求加入具体网站 | 每个站点分别验收和维护；不宣称“任意网页一键播放” |

[yt-dlp 官方支持列表](https://github.com/yt-dlp/yt-dlp/blob/master/supportedsites.md)也说明网站会变化，列入列表并不保证当前可用。它可以作为特定来源解析候选，但不能当作任意影视的通用搜索引擎。此阶段没有运行它或读取用户 Cookie。

## 4. 本机只读核验记录

### Internet Archive

通过官方 [开发者入口](https://archive.org/developers/)及[元数据 API 文档](https://archive.org/developers/md-read.html)核实接口。按官方[自动访问规范](https://archive.org/developers/bots.html)发送描述性 User-Agent；实现时需缓存、限流并尊重 Retry-After。

- 请求 `advancedsearch.php`，条件为 `mediatype:movies AND title:"Big Buck Bunny"`，仅请求 3 条结果。实际返回 JSON，命中总数 107。
- 前 3 条包含自制光盘、影片条目和其他视频转载，说明同名命中需要筛选，数量不能视为可播放的独立作品数。
- 读取公开条目 [BigBuckBunny_124](https://archive.org/details/BigBuckBunny_124) 的元数据，返回 CC BY 3.0 许可字段及一个 MP4 衍生文件。
- 该文件名为 `Content/big_buck_bunny_720p_surround.mp4`，而 API 报告宽高为 **640×360**、时长约 **596.5 秒**。这不是解码实测，却已足以说明不能按文件名中的“720p”标注画质。
- 没有执行 ffprobe、播放器首帧检查或全片播放；上述记录仅证明本机当时能够访问这些 API 并读取信息。

### Blender 官方开放电影

- 本机通过 HTTP 读取 [官方许可页](https://peach.blender.org/about/)，其中说明项目结果采用 CC BY 3.0，标志等有明确例外。
- [官方下载页](https://peach.blender.org/download/)给出新的 4K/HFR 版本目录。
- 实际读取[官方下载目录](https://download.blender.org/demo/movies/BBB/)，列有 `bbb_sunflower_2160p_30fps_normal.mp4.zip`（632,204,510 字节）和 2160p60 ZIP 等条目。
- 仅核验目录和声明，未下载、解压、探测编码或播放；文件名和目录不能独立证明原生制作分辨率或运行性能。

网页工具曾无法读取部分 Blender 页面，本机公开 HTTP 读取成功；不能将工具读取错误当成网站必须付费。

## 5. 对需求的影响

- 搜索结果必须区分正片、预告、花絮、剪辑和未知类型，按作品、季、集及版本匹配。
- 来源状态至少区分待验证、元数据可读、媒体可达、已实际播放、失败/过期；“可播放”应由真实播放证据支撑并带检查时间。
- 清晰度以媒体探测为准；来源声明和实际探测不一致时展示差异。3840×2160 只证明像素尺寸，原生制作 4K 还需出处证据。
- 不因一个连接失效删除作品或播放记录；可以更换源，并防止错切到同名作品、别集或不同时长版本。
- 从“找到更高清候选”到“替换当前版本”需先核验内容身份及字幕/音轨，保留原版本；分辨率较高也可能是低码率放大版本。
- 三部代表剧的验收需要逐项报告：作品匹配、季集匹配、正片来源、实际播放、语言轨道、实际清晰度；没有资源的项如实记录，不编造成功率。
