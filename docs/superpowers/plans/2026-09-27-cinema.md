# 映川 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 构建可运行的Mac个人播放器，接通真实网络来源和边播边画质增强。

**Architecture:** SwiftUI桌面、AVPlayer媒体时钟、Core Image/Metal帧处理；独立CinemaCore负责检索、探测、字幕和记录。先完成纵向可运行链，再依据实际失败补齐。

**Tech Stack:** Swift Package Manager、Swift 5语言模式、macOS15+、AVFoundation、MetalKit、Core Image，Apple低延迟AI在macOS26+按能力启用。

**Spec:** ../specs/2026-09-27-cinema-design.md

## Global Constraints

- 三部指定剧必须在软件内观看；目录条目不等于可播放。
- 不等待整集处理，真实增强模式与尺寸可见；普通GPU缩放不称AI超分。
- 用户没有现成媒体资源；本地文件为补充，不是软件使用前提。
- 原始文件不修改；日志不含网络令牌；不使用账户凭证。
- 所有“通过”必须有当前构建、测试或运行证据，缺集/错集/不可播不能算全集通过。

## Review Focus

- CMS多线路的分隔符、空链接和不连续集数不导致错集。
- 旧搜索/旧播放异步回调不得覆盖新选择。
- HLS相对路径、循环主清单、错误状态和过大响应必须受控。
- seek和切集后旧帧、旧字幕和旧历史不得污染新媒体。
- 4K像素尺寸、AI支持和实时处理速度分别验收。

## Task 1: 来源与媒体核心

Files: Package.swift; Sources/CinemaCore/{MediaModels,SourceService,HLSProbe}.swift; Tests/CinemaCoreTests/SourceTests.swift。

接口：MediaTitle(id,title,year,posterURL,summary,providerID,providerName); Episode(id,name,url,number); PlaybackLine(id,name,episodes); MediaDetail(title,lines); SourceProvider(id,name,endpoint,enabled)。SourceService.search(query:providers:) async -> SearchResponse(titles,failures)，detail(title:provider:) async throws -> MediaDetail；HLSProbe.inspect(url:) async throws -> HLSInfo。

- [ ] 先测试多线路对齐、空URL、数字排序、特殊查询及相对HLS地址。
- [ ] 实现受限请求、错误区分、来源配置及实时目录检索。
- [ ] swift test通过；逐集真实HLS基本探测另存机器可读报告。

## Task 2: GPU流式画面

Files: Sources/CinemaApp/{EnhancementPipeline,VideoSurface}.swift; Tests/CinemaCoreTests/QualityTests.swift; Sources/CinemaCore/QualityPolicy.swift。

接口：EnhancementMode(original,clarity,upscale4K,appleAI)，VideoSurface(player: AVPlayer, mode: EnhancementMode, onMetrics: (EnhancementMetrics)->Void)；指标至少源/输出尺寸、模式名、处理耗时、帧数及回退原因。GPU处理不依赖Core目录模型。

- [ ] 测试等比例目标尺寸、不放大已有4K与预算过载行为。
- [ ] 实现CVPixelBuffer→GPU过滤→MTKView、有限并发、尺寸变化和seek失效处理。
- [ ] 查询Apple真实倍率并尝试适配的AI会话；不支持则清楚回退。
- [ ] 合成片段和网络HLS实际帧处理；持续运行报告记录真实模式占比。
