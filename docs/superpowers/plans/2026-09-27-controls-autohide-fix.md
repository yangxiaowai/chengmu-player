# v0.2.7 控制栏自动隐藏修复

用户明确窗口与全屏都有问题。范围：正常播放闲置3秒后隐藏底部控制栏；全屏顶部同时隐藏；移动鼠标或键盘操作恢复。暂停、缓冲、报错、拖动、菜单和弹窗仍保留控制入口。

根因：隐藏使 SeekBar.visible=false，dismissPreview 无条件发送 onHover(false)，presentation.interact 又无条件 activity，导致控制栏隐藏后立即显示。窗口此前由纯策略和布局同时限定常驻。

实施：交互集合没有改变时不记为新活动；统一播放闲置策略供窗口与全屏使用；窗口底部控制改为画面叠层，淡出时不留下空白栏或改变视频尺寸，外部字幕随控制栏状态避让。

验证：窗口旧策略红灯；独立离屏AppKit窗口驱动实际controller+Timer复现隐藏清理回调自唤醒，再验证持续隐藏、重复退出、真实交互与暂停恢复；全套核心测试；原生两模式空闲隐藏、按键唤醒、预览/拖动后再隐藏及弹窗暂停保护；最终构建签名与压缩包一致性检查。恢复用户第07集1658.078210062秒、窗口暂停、隐藏选集、1倍速、音量0.8、GPU4K。
