# v0.2.6 实施计划

**Goal:** 同一版本覆盖操作可发现性、剧集换源效率、播放状态可靠性。

**Architecture:** 保留 AVFoundation/SwiftUI。命令与精确定位仅调用现有控制器；剧集 UI 从 PlayerView 拆成独立组件；播放状态修复由控制器内部统一处理。

**Tech Stack:** Swift、SwiftUI、AppKit、AVFoundation，macOS15+，无新增第三方依赖。

**Spec:** ../specs/2026-09-27-player-v026-design.md

## 任务与检查

- [x] 根代理：先为 PlaybackTimecode 的秒/MM:SS/HH:MM:SS、非法输入和越界写测试，再实现解析/定位校验。新增 PlaybackCommands 与时间弹窗；scene focus限定命令作用域，编辑时禁用；将时间文字变为点击入口并显示倍速/字幕/音轨选中状态。
- [x] 剧集代理：对取消后迟到结果、原播放意图保持、上一集首末/缺集边界建立回归；实现 AppModel 新接口和 PlayerEpisodePanel。根代理负责接入，代理不写 PlayerView。
- [x] 稳定性代理：用本地真实媒体和明确标注的通知注入先复现状态竞态；最小修复 PlaybackController，覆盖失败/暂停/结束/seek边界，不调整任意缓冲常数。
- [x] 集成后执行核心与相关回归、独立审查，再完成 Release 构建和原生菜单/定位/剧集交互验收。
- [x] 更新使用说明、验收记录、版本和压缩包；保存用户原观影记录和偏好。

## 重点边界

时间输入超大、负数、非有限、秒字段超59和超片长必须拒绝；没有有限片长的流不能使用定位。弹窗/广告编辑时禁止菜单操控背景播放。候选核对期间暂停必须在提交时保持；取消旧任务不能由迟到结果打开新item。旧结束通知不能在跳回中段后触发下一集。已有原生快进/预览/字幕路径应通过针对性回归。
