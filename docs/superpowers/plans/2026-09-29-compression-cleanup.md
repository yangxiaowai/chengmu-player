# 可选残噪清理 v0.3.6

用户已授权继续优化流式修复，沿用先对照、后接入的流程。

1. 比较小半径 guided filter 与受限差分。保留真实影片、平区、弱纹理、细灰字反例；不能只依据平区降噪率判定优劣。
2. 选择源尺寸、单帧、有限改变量的方向门控受限差分。只作为「压缩抑噪」可选模式，原片和流式修复保持原行为。它不是 AV1 CDEF 位精确实现，也不是新的 AI 模型。
3. 排在现有时域降噪之后、放大之前。默认保护画面下方 28% 并叠加已有保护区；不增加未来帧依赖。HDR 原生呈现。几何不可信时不用可能错位的保护区处理。
4. 用两条完整生产管线比较同一真实解码帧，记录三种退化的全部 96 帧与时序误差；合成控制和 GPU 耗时分开报告。收益很小、反例和弱纹理代价同样记录，不自动替换用户选择。
5. 验证偏好保存、目标尺寸、原片比较、seek、普通/插帧几何保护与 HDR 路由。独占 GPU 串行测试，性能结论仅适用于实际测试范围。
6. 生成验收记录和可运行应用，保留旧版本及媒体数据。独立复核确保验证不隐式依赖被清理的构建目录。
