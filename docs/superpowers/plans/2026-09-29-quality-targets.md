# 目标画质、帧率与本机检测

用户已确认 Mac 优先、流式修复、同帧效果比较、可选目标分辨率和帧率、本机性能检测。本轮按既有授权直接实现并验证。

1. 修复明确 SDR 传递函数 + 未指定原色 #2 的错误拦截。只有该受限组合采用显式 BT.709 解释；HDR、宽色域和无法确定传递函数保留原生。
2. 一个统一设置状态持久化目标分辨率与帧率。配置变更拒绝旧异步结果，不替换媒体、不改变播放进度。源帧率区分轨道声明与估计。
3. 在同一解码帧上比较原始/增强，避免播放中来回切换造成错帧观感判断。
4. 本机检测使用真实完成的完整处理路径，预热后记录平均/p95和预算余量；不把耗时倒数称作实际播放fps。
5. 验证 VideoToolbox 真运动插帧的内容、输出PTS、时钟和性能。区分 API 能力、实验目标和持续达标：支持的系统可选择实验目标并自检，超预算自动回退；只有同步与吞吐证据成立才声称已达60fps，不能用重复帧冒充。实测后保留实验入口以满足目标选择与本机自检需求，不因本机吞吐不足永久禁用所有机器的能力；预算门禁不放宽。
6. 完成核心测试、原生GPU/播放回归、可见UI检查、发布构建与安装包校验。
