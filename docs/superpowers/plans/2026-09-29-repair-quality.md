# 修复质量 v0.3.5 定向改进

用户已授权继续改善实时修复。目标是减少被放大器重新加强的噪点，保留色阶、边缘和字幕；不以堆叠锐化或改变 HDR 色彩路径换取表面清晰度。

1. 对现有时域强度 0.25/0.5/0.75/1.0 做独立扫参。结果不支持统一替换默认 0.75：真实片段收益很小，强噪声有反例。
2. 回归测试先覆盖亮度偏置：同幅度噪声在亮部被旧版线性阈值更强地放大。比较保持线性光插值、只把对比度门控转入 sRGB 编码亮度域的候选；记录低对比纹理代价。
3. 新增带明确 SDR 标记的 10-bit 渐变回读测试；先证实旧 8-bit 中间输出会丢失色阶，再试用高精度纹理。保留原有 sRGB 编码输出和 HDR 原生路径，验证局部广告柔化和字幕保护。最终格式由质量和运行成本测试决定。
4. 仅接入通过质量对照的候选，保持模式、目标尺寸和源切换行为兼容。单独记录算法核耗时及完整播放成本，不能把核性能称为真实 60fps。
5. 生成同帧原片/旧版/新版对照和本轮验收记录，编译可运行安装包。测试期间 GPU 串行独占，保留旧版本和用户媒体数据。

探索 CDEF、guided filter 与 RCAS 的资料单独归档。本轮没有验证其端到端收益前，不将它们默认串联进播放链。
