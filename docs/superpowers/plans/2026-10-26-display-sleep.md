# 显示器休眠修复

用户明确要求播放期间不自动变暗，并参考 GitHub 成熟播放器完善体验。本轮范围是电源保活、偏好与播放生命周期；验收以系统实际 assertion 为证。

1. 确认旧控制器无保活，核对本机 SDK 与 IINA、mpv 一手实现。
2. 先跑旧实现的系统 assertion 和旧偏好迁移失败用例。
3. 增加统一拥有者和默认开启的持久化开关；播放意图启用，暂停/结束/失败/退出释放，短缓冲不反复申请。
4. 对原片/增强切换、拖动、回调顺序、偏好开关和析构检查真实系统资源；完成已有播放稳定性回归。
5. 构建并安装 v0.3.8，记录系统登记、打包和物理屏幕验证之间的边界，更新同一 GitHub 项目。
