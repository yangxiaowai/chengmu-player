# 播放体验、稳定性和轻度修复

用户授权继续参考成熟 GitHub 播放器优化三方面，并在完成后同步到同一仓库。

1. 参考 mpv 的相对 seek 合并、IINA 的定位策略和 Apple AVPlayer 定位建议。固定80ms窗口只合并按钮/快捷键的相对跳转，界面目标即时变化；长按不无限延后，绝对定位、换源、关闭及广告跳过的优先关系明确。
2. 先复现暂停后的传输失败通知会自动恢复播放，以及同步相对跳转会反复重置解码；保留首次失败/正常重播等既有回归。失败通知必须遵守当下播放意图。
3. 基于既有强度扫参增加可选的0.5时域档，常规0.75继续保留。沿用相同放大、颜色、HDR原生路径、原片对照和自检；模式切换清空时域历史。用两条真实生产管线对同一96帧×3退化做完整比较，保存负收益帧和已知强噪反例。
4. 验证连续/长按/暂停/绝对定位/换源/真实EOF、保活、偏好、57项流式处理和真实1080p播放。独立代码审查检查排队与广告/片尾竞态。GPU检查串行执行。
5. 编译安装0.3.9，保留旧版，核验安装包和远端摘要后同步GitHub源码、标签及Release。
