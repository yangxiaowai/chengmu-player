# 映川 v0.2：多源片库与日常观看

用户授权继续扩充媒体源、寻找更多影片，并参照成熟播放器完善体验。本轮沿既有 Mac 原生架构增量交付；既有网络播放和流式增强必须保留。主流程不再局限三个种子剧。

## 交付范围

1. 核验至少三个新增目录后加入可选来源；公开目录、详情、HLS、短片段解码逐层记录，失败接口不充默认数量。来源启停、手动健康检测与恢复内置源，保留用户已有开关/自定义项。
2. 聚合检索结果：同标题、同季、同年份的多来源汇成一张卡，详情可选来源。年份不明时只有唯一明确年份才允许合并；不同季、翻拍年份、剪辑版不混合。提供来源/年份筛选、标题/年份排序、分页加载。
3. 扩展发现入口及搜索记录，支持电影、剧集、动漫等常用关键词与可验证的目录浏览；取消旧任务不能覆盖新结果。
4. 收藏为本地“待看”，记录多个来源条目，重启后保留；单条移除历史不影响其他记录；移除当前记录后不由后续进度回调重新写回，清空需明确确认。旧历史兼容，损坏收藏文件不直接覆盖。
5. 播放记住音量、倍速、增强偏好和自动下一集；提供可见的睡眠定时/剩余时间、正确静音恢复、常用键盘交互。失败能直接重试和查找其他来源。
6. 优化空态、载入状态、来源错误、封面占位与详情切换；返回片库不意外再次弹详情。不更换AVFoundation/Metal内核，不把尺寸提升称为原生4K。

## 技术边界

CinemaCore保留纯数据与策略测试，增加聚合/收藏逻辑；SourceService提供有界分页与来源状态；AppModel协调任务及持久化；界面拆出片库视图以控制复杂度。仍使用系统框架，无新产品包依赖。每次目录检索最多3个并行来源请求，最多检索24个启用来源，响应4MiB上限。

成熟体验参考由官方IINA/Jellyfin/mpv资料核对，参考交互模式，不直接复制产品资产。前期稳定的GPU路径不重写，不承诺HDR/全格式MKV/AI4K。

## 验收

核心回归与新增边界测试通过；新增来源记录多类作品和真实解码；Release构建、签名、正常启动；原生UI验证聚合、来源选择、收藏/重启、搜索分页/筛选、健康状态、偏好和播放。对新来源至少实际应用短播放。保留旧版产物及记录，区分v0.1长基线与本轮短回归。
