# 大陆网络来源检查与优先选择

用户新增要求：尽可能使用中国大陆网络无需 VPN 即可访问的来源，覆盖电影、国产剧和美剧。保留已经实现的播放、流式增强、全屏体验。

## 判定与研究方法

目录在线不等于媒体可达。依次验证搜索、同名详情、实际 HLS 和首段媒体；使用公开大陆运营商节点补充观察。由于本机存在代理与隧道路由，本机普通成功不能当作大陆直连证据。额外脚本必须同时约束物理接口和 DNS；不改变系统设置。第三方节点 HTTP 返回、本机字节读取、实际解码和整集观看分别记录。

## 本轮实现

- 沿用 CinemaCore / AppModel / SwiftUI 分层，不替换 AVPlayer 或增强管线。
- Core 增加代表影片的目录→清单→分片检查及可选会话代理设置；既有普通检索和 HLS 预检保持系统路由。
- 分片只取最多 64 KiB 返回数据；检测并非整段下载/解码。每请求8秒、最多5层HLS、目录4MiB、清单2MiB；网络缓冲可超过返回数据上限。
- App 单独维护最多3个同时运行的检查，支持取消、排队、移除后丢弃迟到结果。检测状态不被普通目录查询覆盖，仅在本次会话保存。
- 页面显示三个阶段、样本、时间和失败原因；明确 HTTP 代理排除不代表 VPN 或系统 DNS 已排除。
- 默认优先魔都（对应本轮大陆媒体节点样本）；来源可修改/停用/移除。手动筛选与详情选择仍优先；未选到或停用时回退到可用目录版本。优先仅影响打开聚合作品，不改变当前播放或历史续播，不因一次连接成功自动改变用户设置。

## 验证

解析、错误页/二进制判别、取消、来源选择通过核心测试。队列去重、并发、迟到结果和移除通过不联网的 App 控制器 smoke。物理接口与公开节点证据另存 JSON 和报告。Release 构建及签名后打包。Mac 锁屏时原生界面操作仍标为待验收，不把这些检测宣传为全国全片可用。
