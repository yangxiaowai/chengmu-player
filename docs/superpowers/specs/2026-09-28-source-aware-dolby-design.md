# 根据片源适配杜比与HDR播放

用户已要求完成升级，沿用Mac内置屏幕/扬声器、现有自动广告跳过与实时增强。成功标准是可播放的Dolby Vision/Atmos素材由系统原生处理其原始信息，普通片源保持适当增强；识别/系统配置/实际呈现的证据分开，不将SDR或双声道伪标为杜比。

## 方案

采用系统AVPlayer/AVPlayerLayer：开启逐帧HDR元数据应用，允许系统处理多声道空间化。保持master URL让系统按硬件、带宽和音频路由选兼容变体，不硬选最大分辨率，不擅改语言、音量、系统显示设置。相比新接libmpv或自行实现Dolby渲染，这条路线使用现有原生播放链，兼容当前控制、字幕、全屏和时间轴跳广告。

1. 清单解析保留最外层全部变体、VIDEO-RANGE、CODECS、SUPPLEMENTAL-CODECS及音频组CHANNELS声明。普通HEVC、E-AC-3、4K、音轨名称均不能单独证明杜比。
2. 当前视频轨道格式、Dolby配置原子、PQ/HLG特征和实际HLS变体事件用于片源状态。当前音轨原始codec、EC3SpecificBox扩展或确切选中JOC rendition用于音轨状态。master中存在不等于正在选中。
3. 明确DV/HDR全程原生层，不挂8位增强输出，广告柔化暂停但保留选区。未知源暂用原生；普通H.264或明确SDR格式可经10bit wide-color取帧检测，仅明确709/sRGB的帧进入现有SDR增强。请求输出时不覆盖源色彩；逐帧PQ/HLG/未知均返回原片并作废旧GPU结果，HDR信息锁定本item原生。无DV声明但源格式不可查的HEVC仍保守原生，避免漏掉SDR兼容DV。
4. 系统音频保留原轨，不增加下混/音效插件。自动模式允许多声道空间化；用户可切“保持原声布局”，并继续手动选音轨。普通双声道不被包装为Atmos。片源/音轨/设备变化重新识别，旧item回调无效；不替换播放器或seek来切渲染模式。
5. 播放页新增“视听适配”状态入口，分层显示当前视频、当前音轨、清单可用版本、原生或增强决策、HDR设备可用及屏幕EDR、空间音频请求状态和限制。宏观硬件支持不等于实际Dolby输出，明确未能测量扬声器DSP/杜比认证。

## 验证与发布

Core红绿覆盖清单正负/旧JSON、EC3结构与截断、逐帧色彩许可。真实合成SDR/PQ/HLG素材验证原生与增强路由、切换后旧帧取消、暂停/字幕/广告回归。使用Apple官方Advanced Stream（含DV5、HDR10、SDR、Atmos和普通音频）测试真实系统播放及实际选择证据，不以清单存在代替播放成功。无整片下载，不动用户当前影片。
