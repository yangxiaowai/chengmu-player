# 感知亮度门控对比（2026-09-29）

仅缩放器的配对实验，GPU 串行独占。候选只把 contrast 改成 `OETF(dot(hi,luma))−OETF(dot(lo,luma))`，仍在线性光域插值，并保留线性 coherence、2×2 包络和最大 0.8 权重。每输出新增 2 次标量 OETF。这里是 sRGB 编码的线性亮度代理，不等于逐 RGB 编码再加权的 Y' 或完整感知色差模型。

固定线性门槛对亮部更敏感：原起点 0.012 在灰 64/128/192 附近约对应 7.61/3.29/1.95 个码值差。改用感知亮度门槛后，相同码值残噪更一致。它改善插值选择，不重建不存在的影视细节。

| 方法 / 实际源码 | raw ±8 噪声 MSE/双线性（灰64/128/192） | noisy / compressed 影片 PSNR dB | scaler wall 均值 / P95 ms |
| --- | --- | --- | --- |
| 原版 `DetailScalerBaseline.swift` | 1.0059 / 1.1016 / 1.1547 | 32.34645 / 30.87056 | 3.33 / 4.78 |
| A06 `DetailScalerContrastSRGB.swift`（0.06/0.14） | 0.9993 / 1.0155 / 0.9945 | 32.35879 / 30.88101 | 3.42 / 5.05 |
| A03 `DetailScalerContrastSRGBLow03.swift`（0.03/0.14） | 1.0100 / 1.0270 / 1.0054 | 32.36580 / 30.88720 | 3.51 / 5.72 |

三轮均通过**原有 19 项**；同一时域阶跃保持 64…192、无新增过冲、10–90% 过渡宽度 2px。亮部 raw 噪声增量明显降低，时域后改善较小。A03 两帧 PSNR 比旧版仅高 0.01935/0.01664dB，不是肉眼大幅变清晰或普适质量提升的证据。A03 暗灰 ±8 噪声略高于旧版，也不是处处更低噪。

弱纹理单独使用 8 源像素周期灰阶正弦、灰64/128/192、峰峰码差8/12/16/24/36，对比同一个输出像素中心解析参考，没有时域去噪。候选 A03/A06 在这15个量化样本上的读回指标相同；24/36码差平均调制度由原版0.970/0.978降至0.951/0.964，平均参考 MSE 由0.500/0.375增至0.625/0.625。降噪与弱纹理存在真实取舍。部分低幅样本因8bit量化的调制度超过1，不代表 shader 越过局部包络。

倾向采用 A03，作为较保守的噪声/细节折中；须保留弱纹理代价的说明。更完整的非线性 coherence 候选没有GPU验证，也未并入产品：目前没有证据支持为16个 tap 额外计算 OETF。两种 A 运算数量相同，阈值不同引起的本轮 P95 差异不能当成稳定算法成本差异。60帧计时仅含输入转换、分配、编码及 GPU 完成，不含解码、时域、显示、读回；不能作为整条播放器帧率。

复现三份源码使用本目录 `detail-gate-main.swift` 与仓库 `Sources/CinemaApp/TemporalRestorer.swift`，通过 `swiftc -O -parse-as-library -target arm64-apple-macos15.0` 独立编译；可参考仓库 `scripts/validate-detail-scaling.sh` 的编译参数并替换主测试文件。既有影片夹具位于 `.build/restoration-lab/`，未捆绑在此目录；缺失时影片项会明确跳过，不能声称已重新验证影片。

`manifest.json` 保存三份真实 Swift、扩展测试、报告和日志的 SHA-256，以及时域实现和影片夹具的依赖哈希。报告/日志只移除绝对工作区路径前缀，数值未变。这些档案早于后续正式验收收紧至噪声 `bilinear×1.05+0.05`、弱纹理底线及PNG导出的测试修订；此处19/19不冒充那版新验收结果。
