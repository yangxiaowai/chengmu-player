# 固定时域强度扫参（2026-09-29）

结论：**没有跨全部夹具一致更优的固定强度**。在同一真实影片片段的三种退化中，0.5 的原尺寸与同展示尺寸 PSNR、时间导数误差均优于当前 0.75，但收益很小；独立未压缩强噪声夹具则以 1.0 最好，0.5 比当前 0.75 的全帧抽样 MSE 高 46.9%。本结果不支持无条件降低默认强度，也不支持“Apple 时域普遍过度平滑”的断言。

## 范围和复现

- 设备：Apple M4；Version 27.0 (Build 26A428)。独占 GPU，编译和运行正常退出；没有改生产代码。
- 复用原有 Tears of Steel 第 62–66 秒的 96 帧 × 3 类退化，输入 480×200，参考 960×400，24 fps。这里是同一段影片的压缩、轻噪、重噪版本，不是三部独立电影。
- 四种强度各自使用独立生产 TemporalRestorer，会话内不改变强度；只输入当前帧和前一帧，未来帧数为 0。原片为完全绕过时域的基线。
- 原尺寸比较：将同 PTS 参考用 Lanczos 缩至 480×200；同展示尺寸比较：所有候选都先物化为 8-bit sRGB，再统一用 B-spline 放大至 960×400。没有学习式超分或 DetailScaler 参与，以隔离时域强度。
- PSNR 汇总全部 96 帧的 RGB 平方误差；时间误差汇总 95 对相邻帧的 `(候选[t]−候选[t−1])−(参考[t]−参考[t−1])`，不将真实运动本身算噪声。alpha 不计入。
- 原片输入 SHA-256 与 v0.3.2 的影片报告完全一致；未覆盖输入、历史报告。文件哈希见 JSON。16 张同 PTS PNG 存在 strength-sweep.frames/，仅辅助查阅，不用于替代整段统计。
- 合成夹具复用已有确定性函数：640×360，12 帧，干净 / RGB 独立均匀噪声 ±15；移动矩形、3 px 低对比条纹、在第 6 帧切换位置的粗白色字形。区域 MSE 每隔 2 像素抽样、边界留 16 px；与影片全像素汇总的定义不同。

```sh
swiftc -O -parse-as-library -swift-version 5 -target arm64-apple-macos26.0 \
  Sources/CinemaApp/TemporalRestorer.swift docs/validation/v0.3.5/strength-sweep.swift \
  -o .build/strength-sweep/check
.build/strength-sweep/check docs/validation/v0.3.5/strength-sweep.json .build/restoration-lab \
  > docs/validation/v0.3.5/strength-sweep.log 2>&1
```

本次总计 1,248 次时域封装处理调用（影片 1,152、合成 96），另有 288 次影片原片基线计分。现有报告只测 480×200 / 640×360，不据此宣称 1080p 或 4K 的实时预算已重新验证。

## 下一步可证伪的两个候选

1. **压缩类输入的固定 0.5 配置，仅作为候选。** 本片段四种强度中 0.5 最好，但无压缩强噪声反例清楚，不能直接改全局默认。若引入内容分类，必须先在至少多场景、不同压缩参数、真实低光噪声和真实字幕样本上验证错误分类代价；会话内每帧切强度不可取。已安装 Apple SDK 的 `VTFrameProcessor_TemporalNoiseFilter.h:118–120,145` 明确改变强度会 flush 队列。应以源/场景边界固定选择与滞回为候选，并把分类器算力计入预算。证伪条件：噪声片 MSE 回退、真实纹理/字幕退化、额外重置或总完成时间超预算，则不采用。
2. **优先收紧 DetailScaler 的残噪置信门控。** 当前线性 RGB 4×4 方向一致性 + 2×2 对比门控仍会让随机亮部噪声获得 cubic 权重；既有 v0.3.3 灰192±8数据中，原始噪声 MSE 比 bilinear 高 15.5%，时域后仍高 4.4%。可在现有采样内用亮度梯度残差/噪声归一化信噪比调低低置信区域的 cubic 混合，保留 2×2 范围 clamp 和强边缘字形。不要无差别抹掉纹理，也不要强化压缩块边界。证伪验证：同一时域输出后比较亮/暗平区噪声、压缩块、低对比条纹、移动纹理、细字幕；平区噪声不明显超过 bilinear、字幕无过冲、阶跃边缘不退回 B-spline 的宽度；整段 PSNR/时间误差不退化，1080→4K 的 completed wall p95 额外代价建议不超过 1 ms。该候选本次仅静态提出，没有新实现或测量。

这次数据支持先控制残噪被放大的问题，再讨论内容适配强度；不支持单纯“更大/更小强度一定更清晰”。
