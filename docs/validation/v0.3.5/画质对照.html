少一点放大的噪点，
留住更多渐变。

本轮调整亮度对比度判断，并保留更高精度的 SDR 中间色阶。下面都是程序实际处理的同一帧，没有额外美化。影片中的改进很小，低码率已经丢失的细节仍无法恢复；部分弱纹理会稍柔和。

影片部分只比较空间缩放；原片选项使用保存的双线性同尺寸输出，避免浏览器替换缩放方式。未把时域/AI 模型或插帧的收益归入这组比较。

256 → 877

10 位 SDR 渐变的普通输出，保留的独立灰阶数量。8 位 PNG 不能展示这项精度差异，以浮点回读为证。

−4.6%

指定亮部平区，时域后再放大的噪声均方误差下降。暗部样本略有增加，不能外推为整片观感改善比例。

+0.013–0.015 dB

两张影片测试帧相对旧版的 PSNR 小幅改善。不是主观清晰度分数，也不是原生高清重建。

为什么没有继续加大降噪？

0.25 / 0.5 / 0.75 / 1.0 的固定强度扫参没有找到通用最优值：降低强度对短影片样本略好，却让另一组强噪声的误差升高。因此保留当前时域默认值，优先修正放大阶段的残噪强化。新方案仍保持边缘的局部值域夹紧，但弱纹理调制度略有下降。
