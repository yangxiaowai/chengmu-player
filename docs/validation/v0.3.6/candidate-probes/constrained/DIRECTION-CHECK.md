# 限定追加：更强方向保护 S4

按父任务要求，仅在 S4 做一个预先指定的门控变化；其他受限差分、权重、强边缘门控、范围裁剪、±2 码上限保持相同。没有再扫参数。`probe.py` 默认仍是原候选，通过 `strong_direction=True` 选择本候选。

```text
coherence = (cmax−cmin)/(cmax+cmin+0.001)
direction_gate = 1−smoothstep(0.50,0.85,coherence)
g = direction_gate × (1−smoothstep(12,32,cmax))
```

结果：**更强方向保护改善了一维纹理保留，平区减噪也更好；极弱灰字端点和无单一主方向纹理仍会损伤。** 不建议据此默认接入；如保留为可选实验性轻去噪，需完整管线验证、已知字幕区保护与如实呈现局限。

| 时域后 noisy PSNR 增益 | +0.011991 dB | +0.008100 dB |

九种一维条纹（周期 2/4/8 px × 幅度 2/4/8 码）在强方向候选下都逐像素恒等。局部浮点投影得到 1.00000048 之类数值是评价舍入，图像最大误差确实为 0。

弱灰细字的 8 个丢失像素全部是 H/X 线段端点，其余连续内部笔画获得保护。端点的 3×3 局部方向一致性不足，仍按噪声处理，且新门控在那里比旧门控更强。不能用整体 RMSE 下降隐瞒端点变暗，也不能将“阈值未丢4码灰字”说成字形完全不变：4码灰字最坏误差也是1.375码。

增加了三个**诊断夹具而非参数**：幅度2码的斜向周期4纹理、2px棋盘和交叉正弦。新候选保留斜向纹理/棋盘的内部调制度100%，但复制边界处有变化；交叉正弦 `96 + cos(2πx/4) + cos(2πy/4)` 没有单一稳定方向，新候选仅保留50%调制度（原S4为54.50%）。这说明强方向保护不能替代真实纹理识别。

三种影片时域后亮度 MSE 降幅为 0.243% / 0.400% / 2.492%。采用与主报告相同的生产 float32 输入、共同 SDR 输出裁剪和5个固定帧；双方均不裁剪的对照也保存在JSON。不是全96帧、不是最终放大/播放链证明。

CPU 预热2次、计时5次：强方向候选中位数 480×200为4.013ms、720p为41.341ms、1080p为101.175ms；对应原S4同批为4.046/42.471/99.389ms。只看它们同量级，不将这些采样波动解释成速度改善。没有GPU计时。

复现：

```sh
python3 .build/repair-v036/constrained/direction_check.py > .build/repair-v036/constrained/direction.log 2>&1
```

产物：`direction_check.py`、`direction-results.json`、`direction.log`。所有当前生产输入上最大亮度变化小于2码；常量和強阶跃恒等断言通过。此结果可支持继续作为明确受限的轻噪声候选研究，不能支持“字幕/所有细节无损”或“已经可实时部署”。
