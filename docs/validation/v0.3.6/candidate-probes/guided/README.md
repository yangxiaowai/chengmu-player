# CPU 自引导亮度滤波探针（2026-09-29）

结论：**最弱 `r=1, ε=(2/255)²` 有小幅降噪收益，但会削弱真实弱纹理与细灰字；本结果不支持默认全局开启。** 这里只做独立 CPU 数值实验，没有改产品文件、编译应用、运行 GPU、安装依赖或访问网络。输出不是上线或实时性证明。

## 实现和可复现性

运行：`python3 .build/repair-v036/guided/probe.py > .build/repair-v036/guided/run.log`。

- NumPy + Pillow；半径 1/2，ε `(2/255)²` / `(4/255)²`，每像素亮度修正最多 ±2 个 8-bit 码值，不加锐化。
- 域为 sRGB 编码 RGB 的 `Y′=0.2126R′+0.7152G′+0.0722B′`。`a=var/(var+ε)`，`b=(1-a)μ`，**`q=box(a)Y′+box(b)`**；不会省略系数平均。边界为复制边缘。
- 将受限的 `q−Y′` 加到 RGB，再夹紧至 `[0,1]`；无 `q/Y` 除法。主路径 float64 数值参考；小局部 FP32 分离求和只用于误差核对。
- 直接 box 枚举对比最大误差 `3.33e-16`；独立慢速全算法对比最大误差 `3.68e-13` 码值；20 个灰阶弱纹理 FP32 对照最大误差 `0.000558` 码值。这不证明 GPU 精度或 FP16 可用。
- 评分在浮点输出上计算，不额外进行 8-bit 量化；PNG 只是量化预览。JSON 保存输入 SHA-256、参数、每帧和每个合成样本指标。

## 主比较：现有生产时域后的 5 帧

使用根代理导出的 480×200 RGBA Float32 文件，帧号 12/24/48/72/84；只读 RGB，参考是同 PTS clean 经 CI Lanczos 一次缩小。每种退化是同一 4 秒电影片段的不同版本，不是独立影片。本探针没有再次调用时域处理。

**浮点导出包含超域通道。** 因此输入、原片基线和 clean 参考共享一次 `[0,1]` 夹紧；此预处理不算滤波收益。否则只夹紧候选会出现 23–27 码值的虚假“滤波改变量”。JSON 保留所有原始通道范围和共享夹紧幅度；原导出没有改写。所有最终候选逐帧断言算法改变量 ≤2 码值。

表中为 5 帧 RGB MSE 汇总后求 PSNR，相对同组已时域处理原片的增量：

| 候选 | 压缩片 ΔPSNR dB | 轻噪片 ΔPSNR dB | 重噪片 ΔPSNR dB |
|---|---:|---:|---:|
| r1 ε2² | +0.015848 | +0.024903 | +0.115412 |
| r1 ε4² | +0.019714 | +0.022865 | +0.146203 |
| r2 ε2² | +0.006327 | +0.019038 | +0.113469 |
| r2 ε4² | -0.010659 | -0.004238 | +0.120390 |

最弱 r1 ε2² 在这 15 个时域输出样本上逐帧 PSNR 都略升；单帧最大增益来自重噪片一个低误差样本，不能将其代替汇总收益。更强、更大半径不是统一改善：r2 ε4² 已在压缩和轻噪汇总退化。没有主张可见显著提升、全片时间稳定性或完整显示尺寸收益。

JSON 另有同组 raw→guided 对照、两个已有 PNG 的对照及每版本 5 帧 ffmpeg 软件解码补充。**ffmpeg 补充参考用 bicubic，下采样/色彩链不同，不与上述主比较或 v0.3.5 报告绝对 PSNR 混用。**

## 干净内容与合成反例

合成使用连续编码灰度，种子固定；平区噪声为高斯亮度噪声，强度是标准差，非独立 RGB 色噪声。干净纹理为 4/8/16 像素周期正弦，峰峰码差 4/8/16，灰64/128/192；评分区域避开图像边界。

| 候选 | σ2 平区 MSE/原片 | σ4 平区 MSE/原片 | 8px 周期、8码峰峰纹理调制度 | 弱灰字平均对比保留 |
|---|---:|---:|---:|---:|
| r1 ε2² | 0.327 | 0.668 | 0.816 | 0.613 |
| r1 ε4² | 0.201 | 0.466 | 0.716 | 0.511 |
| r2 ε2² | 0.289 | 0.651 | 0.710 | 0.527 |
| r2 ε4² | 0.173 | 0.453 | 0.478 | 0.500 |

- 无噪声常量平区保持原值，误差仅浮点舍入。
- 无噪声阶跃 64→192 没有超出原范围的实质过冲；约 `1e-12` 码值数值误差，最强候选边缘最大改动 0.259 码值。
- 1px 白字（32→235）与灰字（64→96）全部保留中点阈值召回率 100%，8连通分量数未变；这仅代表给定小字形/斜线，不是任意字幕可读性保证。
- **1px 弱灰字（64→68）是明确反例。** r1 ε2² 平均前景误差 1.549 码、对比仅剩 61.3%，中点阈值召回率 95.3%。r2 ε4² 全部像素落到中点或更低，严格中点阈值召回为 0；这不应表述为肉眼完全消失。
- 干净正弦最弱候选亦损失细节；在最弱、最高频的 4px 周期/4码峰峰样本，r1 ε2² 调制度仅保留约 0.418。不能因为每像素最多只动 2 码就认为细节安全。

这些参数更适合受保护、明确允许轻平滑的区域作后续候选；若下一步研究内容门控或字幕保护，应把本探针弱纹理与弱灰字反例保留为独立门槛。当前不推荐接入默认全局路径，也没有把平区噪声下降写成“细节恢复”。
