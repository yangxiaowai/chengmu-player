# Subtitle comfort validation

- Dedicated `subtitlePreferences.v1` stores global visibility, 18–36 pt text size, background choice and 0–120 pt lift. Existing playback preference bytes are preserved. Nonfinite inputs fall back to 22 pt / 0 pt; finite values clamp to the permitted range.
- `SubtitlePreferencesTests` has three focused tests covering older/partial profiles, clamping/nonfinite inputs, round-trip storage and `--validate` / `--benchmark` isolation. Run through `conda run -n searchformoney --no-capture-output bash scripts/swift.sh test --scratch-path /tmp/cinema-subtitle-core-test --filter SubtitlePreferencesTests`.
- `scripts/validate-subtitle-comfort.sh` independently compiles the actual controller with local PCM/SRT fixtures and offline FFmpeg MP4 subtitle tracks. It opens no window and uses a unique UserDefaults suite. The report enumerates every check and whether native embedded tracks were available.
- The captured controller red log shows a real pre-change failure: importing SRT while paused did not immediately refresh the cue. The first core red command was blocked by this machine's CLT manifest linker mismatch before executing tests; `subtitle-core-red.log` records that environment failure and is not evidence of a failing core assertion. The project `scripts/swift.sh` workaround was then used for the green run.
- UI adds a visibility toggle separate from removing the selected track, comfort menu, S / Shift-Command-S shortcuts, and a bounded text overlay that reserves the measured control height plus the user's lift. Shortcut actions retain the existing focused-command and player-surface guards. App compilation verifies type checking; headless controller checks do not verify native menu rendering, pointer/keyboard interaction, full-screen layout or full-media playback.
- Embedded retry matching uses display name, language and media subtype metadata. A missing or ambiguous match chooses no track rather than accidentally reusing a previous asset's numeric index. This is per-item state; selecting a different film clears tracks, external files and timing offset while retaining global presentation preferences.

- Root native interaction follow-up: isolated production-view host confirmed S hide/show while paused and fullscreen subtitle visibility (3/3); screenshot and precise limits in `subtitle-native-ui.json`. The host was normally quit. Large/lift and no-background bitmap layouts were visually inspected; font menu presence is not proof every nested menu action was clicked.
