# 映川 v0.2.1：沉浸式全屏

日期：2026-09-27。用户要求：全屏时以影片为主体，进度条等控件自动显隐，选集侧栏不占据画面。本轮是既有播放器的界面增量，不更换媒体、音频或增强内核。

## 实现行为

- 按 F、双击画面、点击全屏按钮，或使用系统全屏操作进入全屏。实际状态跟随当前 NSWindow；同时读取系统 styleMask，以处理全屏过渡被打断的情况。
- 全屏不显示右侧选集与播放诊断；顶部标题、返回/退出入口及底部控制栏改为叠加在视频上的渐变浮层，不缩小视频布局。
- 正在播放、窗口活跃且约3秒无操作时淡出控件并隐藏鼠标；移动鼠标、点击或按键重新显示。
- 鼠标停留控件区、拖动进度/音量、菜单展开、弹窗、暂停、缓冲、错误或切换应用时保持控件可见。菜单和输入事件仍交给系统处理。
- Esc、F或退出按钮离开全屏；恢复窗口模式的选集显示状态。返回片库及错误后的查找片源也退出沉浸模式，让目标入口可见。
- 字幕独立于自动隐藏浮层，控件出现时字幕向上避让。画面保持原比例，不强行裁切填屏。
- 同一个 VideoSurface 始终位于相同视图层级；切全屏及控件显隐不更换 AVPlayerItem、不修改增强 generation。隐藏控件同时退出鼠标命中和辅助功能树。

## 结构

`PlayerView.swift`负责条件布局与交互入口；`PlayerPresentationController.swift`负责绑定当前窗口、全屏通知、限定到该窗口的输入观察、菜单/滑块状态、空闲计时与清理；`FullscreenControlsPolicy.swift`提供可独立测试的隐藏条件。

事件观察只读取输入，原样返回 NSEvent，不全局接管快捷键。离开播放器、窗口关闭或视图拆除时移除观察与计时，并恢复鼠标状态及原来的 acceptsMouseMovedEvents 设置。

## 尚待原生窗口验收

CUA本轮再次返回“Mac已锁定，无法自动解锁”。已请求手动解锁，未尝试绕过锁屏。**编译及策略测试不能代替原生全屏效果与鼠标命中验收。**

解锁后需要确认：

1. 影片播放中进入全屏，选集隐藏，画面比例正确且无播放重启。
2. 鼠标移到视频中部后静止超过3秒，仅留下视频/字幕；移动鼠标立即显示控制栏。
3. 拖动进度或音量超过3秒、展开菜单超过3秒，控件保持可操作；暂停/缓冲/错误时可见。
4. 菜单中的Esc先关闭菜单；画面中的Esc退出全屏；F、双击及系统全屏入口均保持布局一致。
5. 退出全屏后原选集开关状态恢复；切换应用、关闭播放器后鼠标正常；重复进出不重建视频输出。

本轮应用包已构建供解锁后使用，不能称为上述窗口操作全部验收完成。
