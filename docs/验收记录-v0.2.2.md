# 映川 v0.2.2：大陆网络来源核查与媒体检测

日期：2026-09-27。用户希望来源尽可能在中国大陆网络无需 VPN 访问。本轮新增连接证据与来源优先选择，不更换播放/增强内核，不把普通代理下的成功扩大为大陆直连结论。

## 交付行为

- “媒体来源”可设置打开聚合作品时的优先来源，默认魔都。手动来源筛选及详情手选优先；停用或移除的来源不会自动选用，偏好不可用时回退到现有可用版本。已有播放、历史续播不被偏好改变。
- 每个来源可单独“查目录”或“检测媒体”。后者依次搜索代表影片、核对详情标题/来源 ID、解析 HLS、读取首个分片前缀；三个阶段分别显示，附样本、时间与失败原因。
- 检测全部仅针对已启用来源；也可手动检查停用来源。最多3个逻辑检查槽位、支持排队/去重/取消。取消和移除后旧任务不能覆盖新结果。底层传输取消有异步退场时间，立即重测时不承诺物理连接数量瞬时严格等于逻辑槽位数。
- 应用检测会排除 HTTP/HTTPS/SOCKS/PAC 代理；VPN 路由和系统 DNS 仍可影响结果。只读检查系统代理/隧道迹象并提示，不自动改任何网络设置。普通目录检索和 AVPlayer 播放仍遵循系统配置。
- 分片返回数据最多64 KiB，忽略 Range 的响应也会停止收集；URLSession 缓冲/在途字节可能更多，不能称为严格64 KiB网络流量。单请求8秒、最多5层HLS，整个来源检查并非总计8秒。目录4MiB、清单2MiB。
- 长 HTML、带 BOM 的 HTML/JSON 错误页不会直接被认成媒体；不因加密字节开头恰为标点而误拒。读取成功仍不证明解密、解码、剧情身份、原生4K或整片可播。自定义目录找不到默认代表样本时显示媒体尚未验证，不把“未收录样本”等同于网络失败。

## 本轮来源证据

本机当前启用了代理并有 TUN 路由，因此先前普通播放/网络探测不计为大陆免VPN验收。开发期额外物理接口探针采用 curl `--interface en0 -4`，逐请求确认 socket 绑定；DNS 自身也绑定接口，使用 AliDNS 官方223.5.5.5启动地址和TLS校验，逐重定向主机通过 `--resolve` 保持域名/SNI验证。不改系统代理、DNS、VPN、路由。

| 来源 | 本机物理接口代表样本结果 | 本轮大陆公共节点情况 |
| --- | --- | --- |
| 电影天堂 | 《怪奇物语第一季》搜索、详情、HLS、2个分片前缀通过 | 未新增公共节点测试 |
| 魔都 | 《怪奇物语第一季》搜索、详情、HLS、2个分片前缀通过 | 目录177/252个200；该片子清单258/270个200，首分片230个200+31个206/270节点 |
| 非凡 | 搜索成功，详情连接超时 | 未新增公共节点测试 |
| 如意 | 搜索TLS握手失败 | 目录仅1/271个200，本轮不作为优先来源依据 |

大陆公共节点由 ITDOG 标注地理/运营商，覆盖电信、联通、移动；未独立审计出口。它只展示HTTP响应，未取得远程节点字节解码。魔都首分片的206与200单列，未冒称每个节点完整下载。物理接口出口所在地未独立核验，因此本机结果也不单独称为大陆直连认证。一次超时/TLS错误不推定永久不可用或网络封锁。

证据：[调研与来源链接](research/mainland-connectivity.md)、[大陆节点记录](validation/v0.2.2/mainland-public-node-samples.json)、[物理接口报告](validation/v0.2.2/direct-media-physical.md)、[完整请求记录](validation/v0.2.2/direct-media-physical.json)。旧版只排除显式代理的探测另存 [direct-media.json](validation/v0.2.2/direct-media.json)，未改写成物理接口结果。物理探针仅在内存读取媒体前缀，没有保存影片文件或密钥。

## 未完成的原生窗口验收

本轮 CUA 首次取应用返回 `cgWindowNotFound`，随后系统清单明确返回 Mac 锁定，无法自动解锁。没有绕过锁屏。来源页的视觉布局、按钮点击和v0.2.1全屏交互仍待解锁验收，见[状态](validation/v0.2.2/native-ui-status.json)。核心测试、HTTP采样、控制器smoke不替代原生UI或整集观看。

未重复v0.2媒体解码/GPU基准，因为本轮没有修改增强/解码管线；旧结果作为历史证据保留。应用仍不能承诺所有影片达到原生4K、全国各网络持续可播或全格式支持。

## 使用与复现

退出旧版后打开 `dist/映川.app`（0.2.2/build4），在“媒体来源”选择优先目录或运行媒体检测。安装包为 `dist/映川-v0.2.2.zip`。

```bash
bash scripts/swift.sh test
bash scripts/build-app.sh release
python3 scripts/probe-direct-media.py --self-test
python3 scripts/probe-direct-media.py --physical-interface en0
```

最后一条依赖当前Mac支持物理接口绑定；失败不能静默回落系统路由。报告包含检测时间；后续重测应另存文件保留原证据。应用本身不依赖Python/curl脚本。
