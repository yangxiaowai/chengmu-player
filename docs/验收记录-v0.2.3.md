# 映川 v0.2.3 验收记录

日期：2026-09-27。交付版本 0.2.3 / build 5，Apple Silicon，本机 Apple M4。应用为本地 ad hoc 签名，未公证。

## 本轮需求及实现

用户确认处理对象为画面中的广告文字、网址或贴片，并选择“手动框选广告区，局部柔化，设置字幕保护区”。本轮同时完成单击影片画面暂停/继续。此前媒体来源与大陆连接证据保留，未把这次局部播放测试扩大为新的来源稳定性验证。

- 单击画面等待系统双击间隔后切换播放；双击只切换全屏。拖动、右键、控件操作、切集、窗口失焦及视图退出会取消未执行的单击。
- “广告柔化 → 框选广告与字幕保护区”暂停画面供编辑。黄色矩形为广告，绿色矩形为字幕保护，红色表示冲突。底部 28% 默认保护，最多另加 6 个保护框和 6 个广告框。
- 字幕保护优先。广告框触及保护区及保守边距时整框拒绝；后添加保护区覆盖已有广告框时禁用“应用柔化”，直到移除冲突框。默认保护带不能在编辑器中删除。
- 在现有增强之后，仅对批准矩形的内部像素模糊并合成，不读取矩形外部作为模糊输入。软字幕仍在视频处理之后独立绘制。原片模式下启用柔化也走 GPU。
- 关闭柔化显示原画面，不改变媒体文件、字幕文件或音轨。换集、换源、重新打开影片会清空选区；同一影片失败重试保留。取消编辑恢复原配置及原播放意图；期间有其他暂停或错误时不会擅自恢复播放。
- 特殊像素比例、裁切或显示几何不明确时拒绝柔化。GPU 超时或处理失败回退原片时，明确提示广告区也恢复原画面。

### 原生交互观察

1. 窗口画面单击暂停，进度停止；再次单击续播。双击进入全屏后仍在播放，没有先暂停。
2. 全屏播放约 3.5 秒无操作后，辅助功能树只剩影片画面；单击隐藏控制栏状态下的画面，控制栏显示且播放暂停。Esc 返回窗口。
3. 在暂停测试卡右上角圈选 `AD example.test`，应用后该处明显模糊，底部 `SUBTITLES - KEEP THIS TEXT` 仍清晰。原暂停进度保持不动。
4. 尝试将底部字幕框成广告，界面显示“与字幕保护区重叠，整框不应用”，没有增加广告框。新建保护区覆盖已有广告框时，“应用柔化”禁用并提示冲突。
5. 关闭柔化恢复清晰广告原画；取消冲突编辑维持原暂停与配置。播放中进入编辑并取消后恢复播放，原柔化配置继续有效。
6. 原生测试发现暂停时首帧处理成功但状态仍显示“正在准备”。修复状态发布节流后重建并重启；最终构建在暂停帧应用后立即显示 `960×540 → 3,840×2,160 · GPU 增强至 4K + 局部柔化（1框）` 与“已柔化 1 个区域”，播放按钮保持暂停状态。

测试完成后已恢复用户原先的《怪奇物语第一季》第 07 集、非凡线路、GPU 4K、音量 0.8 和全屏暂停，位置在原记录稍前（24:04，原记录 24:09）。测试卡历史仍可在“继续观看”找到。

## 明确限制

这是局部模糊，不能重建广告遮住的真实背景，也不自动识别或追踪移动广告。字幕出现在顶部、中部或移动位置时，需要额外设置覆盖其活动范围的保护区；与广告重叠时保留原画面。底部 28% 不是全片字幕绝不受影响的保证。

本轮没有完整观看网络剧集来核验真实广告，也未验证外部软字幕的全部样式、HDR 柔化、Apple AI 模式组合、所有显示器/窗口尺寸或整集音画同步。合成 GPU 像素比较与原生测试卡只证明其覆盖的场景。已有 4K 模式表示输出像素尺寸，不等于原生 4K 细节。

调研方法与一手参考见[广告处理调研](research/overlay-ad-removal.md)；使用说明见 [README](../README.md)。
