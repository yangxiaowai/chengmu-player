# 映川 v0.2.4 验收记录

日期：2026-09-27。版本 0.2.4 / build 6，Apple Silicon，本机 Apple M4。本地 ad hoc 签名，未公证。

## 需求与方案

用户要求进度条悬停显示对应画面，并明确“点击没反应”主要发生在播放/暂停、快进快退。本轮沿现有原生播放器实现，没有更改来源优先级或画质处理算法。

- 进度条使用原生 NSSlider 绘制与键盘支持，通过独立预览控制器显示时间和缩略图。普通悬停不提交 seek，拖动松开时只提交最终位置。预览浮层不拦截点击，两端位置限制在进度条内。全屏预览期间保持控制栏可见。
- 本地文件先使用 AVAssetImageGenerator；普通 HLS 使用独立、静音的 AVPlayer 与 VideoOutput，避免依赖主播放器跳转。Apple 文档说明 HLS 图片生成需要 I-frame-only rendition，因此不能把文件取帧方案直接当作所有 HLS 的实现。
- 150ms 防抖，只保留最新请求；最多缓存 48 个缩略图，每张不超过 320×180。接受目标前后 0.45 秒内的实际视频帧，实际帧跨秒时另显示帧时间。超时/失败明确提示，清除旧图，移出或换集取消解码。
- 播放/暂停依据同步发布的播放意图切换；快进快退从最新待提交目标累计。控件可点击区域扩大至 36×36 pt。

## 问题定位与修复

1. 快速暂停后恢复时，旧逻辑同时读取异步 isPlaying 与 wantsPlay，旧 KVO 状态会把第二次点击也当作暂停。现统一依照 wantsPlay，并立即更新图标。
2. 快进的异步周期回调曾把旧进度写回；从 20 秒连续三次 +10 可能只到 40 秒。现使用请求 ID 和待提交目标，拒绝旧 seek 回调，周期回调读取当前媒体时刻。
3. 原生测试发现事件坐标有效后又读取全局鼠标坐标，远程输入下会错误关闭预览。现在鼠标按下、拖动、松开全部使用事件坐标，并在松开时提交最终位置。
4. 拖动时窗口失焦会取消提交并撤回临时滑块值；切集/视图销毁清理交互状态，避免残留虚假进度或全屏控件常驻。

## 范围与限制

缩略图显示原始视频帧，不应用增强、广告柔化或外部软字幕。网络预览需要额外媒体请求和解码，首次访问可能等待数秒；不支持的编码、受限媒体、直播无有限时长或网络失败会显示暂不可用。缓存和请求取消限制开销，但没有证明所有公网来源或低带宽设备下的性能。

自动化原生工具没有独立 mouse-move 接口，因此界面观察覆盖拖动后停留预览；普通不按键悬停另由事件级回归覆盖。未把回环 HLS 测试当成全国网络、所有影片或完整剧集验证。

复现命令：`bash scripts/swift.sh test`、`bash scripts/validate-seek-preview.sh`、`bash scripts/validate-seek-bar.sh`。预览脚本需要开发机 FFmpeg 生成合成样本，发布应用不依赖 FFmpeg。

一手参考：[Apple 视频帧生成说明](https://developer.apple.com/documentation/avfoundation/creating-images-from-a-video-asset)、[AVPlayer seek 完成语义](https://developer.apple.com/documentation/avfoundation/avplayer/seek(to:tolerancebefore:toleranceafter:completionhandler:))。
