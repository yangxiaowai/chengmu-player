# 映川 v0.2.5 验收记录

日期：2026-09-27。版本 0.2.5 / build 7，Apple Silicon，本机 Apple M4。本地 ad hoc 签名，未公证。

用户明确本轮对象为应用左侧导航：探索、待看、历史、媒体来源。沿此前点击响应问题处理现有侧栏，也覆盖画质工作室及底部打开入口。

## 定位与修改

旧版原生窗口（2500×1640 截图）在继续观看页，连续两次点击“我的待看”行右侧空白坐标 `(330,484)`，页面不变；点击文字 `(160,484)` 立即切到待看。普通 Button 的标签没有为 Spacer 和透明留白定义完整点击区域。

新增共用 SidebarButton，将满宽、至少 44pt 高的标签设为矩形点击区域；保持原 Button 行为，提供选中、悬停和按下背景。当前页保留高亮与金色标识，并向辅助功能发布 selected 状态。底部本地影片/网络链接入口采用同样的点击区域。

原“探索”导航每次都调用 discover，清空搜索、结果、筛选和分页并重新请求推荐关键词。现在导航仅切换 section，保留上述状态；启动加载、提交搜索和媒体来源页的显式刷新仍保留。

## 验证

- Release 构建通过，原生应用退出重启后验证最终构建。
- 分别点击五个导航的右侧空白区（x=330），均立即显示对应页面；辅助功能 selected 状态随之更新。
- 点击底部本地影片/网络链接的右侧空白区，分别弹出系统文件选择器/链接输入框；均取消，没有导入或修改片库。
- 搜索已有关键词“怪奇物语”，得到 14 部作品、39 个来源版本；切到待看再从右侧空白区返回探索，关键词、结果数量与作品列表保持，没有出现新的加载指示。这是导航保留验证，不是新增来源播放认证。
- 既有 97 项核心测试、14 套件通过，见 `validation/v0.2.5/tests.log`；此低影响 UI 改动以原生复现和复验为主要证据，未增加镜像实现的静态测试。
- 签名、ZIP CRC 与压缩包可执行文件一致性见 `validation/v0.2.5/release-manifest.json`。

结构化原生记录见 `validation/v0.2.5/native-ui.json`。自动化工具没有独立鼠标移动/按住截图接口，悬停与按下颜色由代码审查确认，未声称对其进行了单独的视觉验收。筛选/分页字段未被导航修改，但没有额外执行多页联网验收。播放、预览、增强及字幕处理代码未在本轮更改。

测试结束恢复《怪奇物语第一季》第 07 集、非凡线路、1444.6717 秒、全屏暂停、音量 0.8、1×、GPU 4K。
