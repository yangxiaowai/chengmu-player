# 映川 v0.2.8 验收记录

日期：2026-09-28（部分测试在9月27日完成）。版本0.2.8 / build 10，Apple Silicon，验证设备Apple M4、16GB。系统自带Vision、AVFoundation；不增加运行依赖或云端模型服务。

## 本次行为

用户要求通过视频帧自动识别、剔除剧情中混入的“澳门新葡京”广告。本轮实现播放过程中的自动跳过，不修改远端媒体、本地原文件、HLS清单或字幕文件。

- 默认开启“自动跳广告（实验）”，开关保存在本机，兼容旧版偏好。菜单可查看分析状态、已分析帧数与识别段数。
- 独立静音解码器分析前方45秒，每2秒取样，输出最高960×540的原始画面，使用Vision accurate中文OCR。最多一个扫描任务，串行后台图像处理；暂停、拖动、缓冲、关闭功能或换片时停止当前任务并隔离晚到结果。窗口已扫描完后复用解码器，避免每次补扫重新准备HLS。
- 显著居中的“澳门新葡京/新葡京”品牌与独立促销文字同时出现，连续至少3帧、跨度至少4秒，并有后续普通画面确认结束，才产生跳过候选。取帧失败、重复帧、无效时间、unknown或时间间隙不作为可信结束边界。90秒以上连续候选不自动跳过。
- 底部28%及用户额外指定的字幕保护区不参与广告判定；普通字幕、角标、单独品牌文字均有负样本验证。软字幕不在分析帧中，跳过后继续按原视频时间轴显示。
- 播放到确认区间内部才跳转。提示提供“撤销并暂停”，返回跳过前位置并在本次影片会话忽略该区间；手动拖进已识别区间也允许回看。换集和换源清空区间、撤销和忽略状态。
- 正常播放优先：不强制等待扫描，不暂停主视频来预处理。识别需要额外读取前方片段和解码，网络慢、冷启动或流格式不支持时可能来不及跳过。不能识别时继续原片播放。

设计与实施计划见 `superpowers/specs/2026-09-27-local-ad-skip-design.md`、`superpowers/plans/2026-09-27-local-ad-skip.md`。

## 验证与证据边界

`validation/v0.2.8/` 保存原始日志和JSON：

- `ad-policy-red.log`：空策略基线产生真实断言失败；`ad-policy-ocr-offer-red.log`：实际OCR读到“注册即送”后暴露的推广词缺口，先加回归再修复。
- `preferences-red.log` / `preferences-green.log`：旧配置默认开启与关闭状态持久化的失败及通过记录。
- `tests.log`：131项核心测试、17套件通过，包含26项广告识别/时间区间策略测试。
- `ad-scan-green.json`：14项真实Vision/AVFoundation检查通过。包括中文广告、普通剧情、字幕品牌、角标、品牌单独、自定义保护、MP4、普通HTTP HLS、控制器扫描、暂停、换片、取消和失败。40秒夹具的实际插播为16–28秒，0.5秒起始的采样识别出16.5–26.5秒主段。
- `ad-scan-red.json`是旧版没有扫描能力的功能缺失预检查，**不是**旧版真实OCR执行结果。`ad-scan-cold-start.log`记录首帧模型冷启动18.01秒；后续热启动约0.27秒，不能仅用热启动代表首次播放。
- `ad-skip-playback.json`：10项真实主播放器与本地OCR的集成验收通过。以0秒为网格起点识别16–26秒主段，实际AVPlayer执行跳过，28秒后的外部字幕仍正确显示；撤销暂停、手动回看、关闭开关、切片隔离以及在途跳转干预均逐项记录。
- `control-visibility-green.json`、`responsiveness-green.json`、`episode-source-green.json`、`playback-stability-headless.json`：既有控制栏12项、连续操作8项、选集换源11项及稳定性13项共44项回归通过，详见各JSON。

## 限制

没有已标注的真实网络广告样本，因此本轮不声称真实片源广告识别率、所有博彩广告可去除或零误跳。合成MP4与普通HLS通过，不代表加密媒体、所有CDN或所有格式均可取帧。声音广告、无清晰文字、其他品牌、动画过快或位于保护区的广告可能漏检。

范围只覆盖首末确认广告帧之间；本次12秒插播保留末端约2秒。选择保留未知边缘以降低误跳剧情风险，不能称为完整无缝剪辑。原媒体没有删改，内嵌字幕随媒体seek，外部字幕保留原时间轴；本轮实测字幕同步是合成外部SRT，不代表所有内嵌字幕格式验收。

本功能不调用DeepSeek或其他云API，不上传视频帧。未更改杜比/HDR/画质增强能力，上一轮杜比研究文件保留。

## 发布与原生界面

Release构建成功，独立静态复审没有剩余可确认的P1/P2。签名严格检查、ZIP CRC以及ZIP内程序与应用SHA256一致性均通过，见 `release-manifest.json`；仍为本地ad hoc签名，未公证。

使用相同生产PlayerView/控制器源码单独编译的原生验收程序完成界面检查，独立bundle ID和测试片库，不启动来源搜索。实际全屏自然播放出现“已跳过插播主段 00:16–00:26”，32.20秒显示广告后的外部字幕；点击“撤销并暂停”回到16秒，播放键变为继续；再次播放到20.20及23.00秒没有反复跳转。菜单关闭开关后显示“自动跳广告 · 关”。见 `native-ui.json`。这是隔离应用源码级原生界面验收，不是将发布包用于用户当前影片的验收。

初版测试壳的脚本启动器造成CUA连接超时，改为单一原生入口后恢复；没有因此改动生产代码。本轮原生界面操作没有另行声称独立空闲自动隐藏或画面鼠标单击验证，相关逻辑仍有12项控制栏及8项响应回归证据。

用户现有映川播放进程保留，不为了验收强行重启或跳转；新版本需退出旧进程后重新打开才能生效。
