# 映川 v0.3.0 播放页验收记录

日期：2026-09-28。版本 0.3.0 / build 12。本轮针对播放器的视觉层级、操作密度和窄窗口可用性，不修改媒体检索、解码、增强或广告识别算法。

## 实现

- 视频铺满播放区域；顶部把返回、片名/集名、视听适配和选集收进同一层渐变浮栏。全屏沿用同一布局，右侧选集始终隐藏。
- 选集默认折叠，展开后以 300 点侧栏区分当前节目、线路、剧集和替换片源；剧集项保留至少 44 点的点击高度。底部只放进度条与一排常用动作，播放键突出显示，图标控制使用约 42–48 点目标。
- 画质、速度、字幕和音量各有明确入口；广告柔化、自动跳过、睡眠定时、播放信息等低频功能进“更多播放设置”。跳过撤销和字幕提示改为右上角通知，撤销/关闭目标至少 36×36 点。
- 顶部与底部普通按钮的静止悬停不再永久标记为交互，因此播放中仍可在闲置后隐藏；进度预览、拖动、菜单、跳过通知和暂停等继续按现有策略保持可见。外部字幕继续按底部控件高度避让。画面单击播放/暂停、双击全屏、快进快退与键盘快捷键仍调用原控制路径。

设计约束与组件拆分见[播放页视觉设计](design/player-chrome-v0.3.md)。

## 验证

| 检查 | 结果 | 范围 |
| --- | --- | --- |
| `bash scripts/swift.sh test` | 152 项、19 套件通过 | 核心模型与策略回归；不等于原生鼠标验收 |
| `validate-control-visibility.sh` | 12 项通过 | 真实 `PlayerPresentationController` 计时器与发布状态；无物理指针注入 |
| `validate-seek-bar.sh` | 7 项通过 | 无窗口 AppKit 合成事件：悬停不跳转、拖动提交、取消、失焦等 |
| `validate-seek-preview.sh` | 通过 | 本地 MP4、普通 HLS、旋转视频、快速悬停、缓存与主时钟隔离 |
| 独立原生 QA 应用 | 1250×820、1040×680 的收起/展开选集及全屏均已目视检查；1040 点下常用按钮仍在窗口与辅助功能树中；播放键通过辅助功能触发后切换为暂停；更多菜单及播放信息入口可打开 | 使用本地合成 40 秒片和独立应用标识，不占用用户正在运行的旧版应用 |
| 最终代码的独立 QA 复核 | 1040×680 播放页已目视检查；播放/暂停与跳过通知的撤销、关闭按钮出现在辅助功能树中 | 测试片画面自带大字和外挂字幕同时出现，是夹具内容，不是控件文案 |

控制栏隐藏策略的 12 项报告在 [`control-visibility.json`](validation/v0.3.0/control-visibility.json)；进度与预览报告同目录。最终独立 QA 应用由最终源代码构建，但原生自动隐藏期间的前台焦点/物理指针状态未能稳定控制，故本轮**不把截图或辅助功能观察写成“原生指针自动隐藏通过”**。普通悬停阻止隐藏的问题由代码审查定位并移除，计时器回归覆盖控制器行为。进度条真实指针悬停预览、画面空白区域单击、VoiceOver 自定义动作仍待手工操作核验。

## 交付与边界

- `dist/映川-v0.3.0.app`：Apple Silicon、macOS 15+ 的本地 ad hoc 签名应用；`codesign --verify --strict --deep` 通过。`dist/映川-v0.3.0.zip` 通过全文件 CRC 校验；用 macOS `unzip` 与 `ditto` 解包后，可执行权限仍在，签名校验通过，文件字节与原应用一致。文件哈希和版本记录见 [`release-manifest.json`](validation/v0.3.0/release-manifest.json)。
- 旧版 `dist/映川.app` 及其正在运行的进程保持原状。使用新版时需先退出旧版，再打开新应用。
- 本轮是界面改版。第三方网络片源的长期可用性、整集观看、原生 4K/杜比实际输出和广告识别在真实剧集上的准确率，仍按之前的验收记录理解，不能由本轮 UI 回归推出。
