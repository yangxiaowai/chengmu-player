# 映川 v0.3.4：色彩兼容、目标画质、同帧对照与性能自检

2026-09-29；Apple M4 / 16 GB / macOS 27.0。版本 0.3.4 / build 16。本次没有更换片源或改动系统网络配置。

## 已实现的用户功能

- 播放页画质按钮和画质工作室使用同一设置面板。源分辨率、源帧率、所选目标、实际输出和回退原因分别显示；帧率来自轨道或逐帧估计，两者明确区分。
- 目标尺寸可选自动、片源、720p、1080p、1440p、4K。六种既有模式保留，目标保持比例；显式较小目标允许缩小，不把缩小后的运算冒称原尺寸处理。设置会保存，并兼容旧偏好文件。
- macOS 26+ 且系统声明运动补偿能力时，提供“60 fps目标（实验，可能回退）”及“尝试1080p60”。它是可试验的目标，不是本机持续达标保证。超过 1080p 的插帧明确拒绝，仍可按源帧率做 4K 空间修复。
- “同帧分屏”左边原片、右边修复，使用同一解码时间戳、方向和显示比例；为保证比较同一源帧，分屏暂不插帧。外置字幕仍在上层显示。原片临时对照保持选项和播放位置。
- “开始自检”暂时暂停播放，独占处理队列，用固定合成 SDR 运动/噪声样本走实际完整处理路径。预热后测 30 个源帧间隔，显示平均、P95、超预算次数和真实输出尺寸；插帧还验证时间格点和生成帧计数。支持取消，用户换片或改变播放意图后不会擅自恢复播放。

## COLORPRIMARIES#2 的处理

`#2` 表示未指定原色，不等于 HDR。旧门禁始终等待后续标记，部分 SDR 视频因而无法增强。现在仅在**明确 SDR 传递函数**及**可识别 YUV 矩阵**时，按 BT.709 原色解释未指定/缺失原色；保留传递函数和矩阵，不修改 AVPlayer 拥有的缓冲附件。界面标注“色域未指定，按 SDR BT.709 原色处理”。

缺失/未知传递函数、Log、PQ、HLG、P3、BT.2020 仍保留原生。没有捕获用户原始报错流，不能把合成及本地 HLS 通过等同于该网络片源已实机复现并修好。

[54 项颜色验证](validation/v0.3.4/unspecified-sdr.json)通过，包括真实 H264 / 本地 HLS、sRGB 传递函数保持、不修改输入附件和 HDR 拒绝。未指定原色的兼容输出与正确 709 标签参考逐像素差为 0/255。修复前的[失败证据](validation/v0.3.4/unspecified-sdr-red.json)保留。

## 实际画质对照

[交互同帧对照](validation/v0.3.4/画质对照.html)提供并排画面及固定位置 2 倍放大切换。影片样本为《Tears of Steel》的人工加噪片段，480×200，同一 PTS 1.000 s；输出来自真实时域修复。背景和面部颗粒减弱，颜色/明暗接近原片，模糊纹理仍然模糊。没有把样本缩放或去噪称为恢复原生 4K 细节，也没有声称所有影片都改善。

运动真值测试中，生成中间帧的 ROI MSE 约 2.43，普通像素混合约 241.62、复制前帧约 423.76。这个对照证明有真实运动补偿，不证明播放器已持续呈现 60 fps。算法、SDK 与论文/开源方案链接见[帧率研究](research/frame-rate-2026-09-29.md)及[前轮恢复调研](research/restoration-papers-2026-09-28.md)。

## 连续播放发现与修复

1. 反复给主 item 移除/挂载 video output，即使完全不增强，也会触发 AVFoundation 回关键帧：5 秒内 18 次 TimeJump，媒体时钟仅推进约 0.085 秒。现改为同一 SDR item 复用一个输出，原片对照和视图返回不反复拆装；HDR/nativeOnly 仍清除所有属于本播放器的输出。
2. 视图停止会拒绝迟到的 GPU 和资产加载回调，避免旧视图在新原生视图上重新挂回 SDR 输出。显示与计算使用独立 Metal 队列及 CIContext，颜色合同保持一致。
3. 插帧使用独立静音解码器的当前时间预读约 0.30 秒，主音频时钟不被 seek/调速。源队列与成品队列有上限，拖动、暂停、原片对照、切镜和设置变更清理旧参考；局部广告柔化启用时保留源帧率，避免破坏选区和字幕边界。
4. 预热只在仍及时的真实运动插帧存在时进入“就绪”，参考帧或已过期的冷启动结果不能解锁展示。落后主时钟超过 120 ms 或处理持续超预算时，退回空间修复＋源帧率；回退首帧不会倒退到已呈现插帧之前的源锚点。

输入缓存将连续 20 对的全尺寸转换由 40 次减至 21 次，19/19 对命中，像素与旧版完全一致。但完整链 ABBA 均值为 46.56/39.76/52.83/45.56 ms，波动较大；未证实稳定加速。独立显示队列也没有使本机 1080p60 达标，不以代码优化数量代替结果。

以上完成帧计数是 Metal 命令成功完成的独立 PTS 计数。当前 Mac 锁屏，drawable 实际呈现回调为 0；不能称为实际屏幕帧率、主观音画同步或可见界面验收。没有进行整集/长时热稳态、所有网络来源、真实 HDR/Dolby 母版或所有 Mac 型号验证。实验 60 fps 选项按系统能力开放，运行中仍执行原有性能门禁；默认帧率跟随片源。

一次误用默认1080目标的诊断轮曾15/15、约60.18个完成帧/秒，但与另一个验证进程的时间边界无法完全排除重叠，之后独占复测没有重现。因此保留其原始数据，不用它覆盖失败或宣传稳定60。最新helper16项与该轮也可能相邻/重叠，仅用于正确性，不引用其处理耗时。
