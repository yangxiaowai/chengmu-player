# 澄幕 v0.3.7：更名与 GitHub 发布

应用显示名与安装入口由“映川”改为“澄幕”，仓库名为 `chengmu-player`。播放器功能沿用 v0.3.6；历史验收记录仍使用发布时的名称。

内部 bundle ID 保留 `local.yingchuan.cinema`，以继续使用当前 Mac 的观看历史和偏好。安装程序同时识别旧的 `映川.app` 与早期 `映川-v0.3.0.app`，先检查运行状态，再将旧版移到 `dist/历史版本/`。已实测安装新包后旧 `映川-v0.3.6-build18.app` 进入历史版本目录；未强制停止播放器。

本轮本机核心测试 **160 项/20 套件通过**，Release 编译成功。`dist/澄幕.app` 和 `dist/澄幕-v0.3.7.zip` 均经签名核验；ZIP 完整解压、CRC、可执行文件一致、显示名/版本与旧 bundle ID 核对通过。详情见[发布清单](validation/v0.3.7/release-manifest.json)。没有在真实屏幕上重新验收所有播放交互，也未进行 Apple 公证。

GitHub 仓库不包含 `dist/` 安装包或 `.build/` 缓存。安装包作为独立 Release 附件发布时，以发布页实际附件为准。本地 Git 历史和本轮源码、研究、验收记录保留。
