# v0.3.8 播放时屏幕常亮

2026-10-26。修复播放时显示器仍按空闲计时变暗/休眠的问题。控制器此前没有申请保活；macOS AVPlayer 的相关属性默认关闭。新版本由控制器统一申请显示器保活，适用于系统原片和自绘增强画面。

播放界面“更多播放设置”提供“播放时保持屏幕常亮”，默认开启，旧版偏好也迁移为开启；关闭立即生效并保存。暂停、片尾、失败后同步释放，准备/短时缓冲/拖动期间维持。退出时主动暂停并取消睡眠定时，拥有者析构配对释放。系统返回失败码时显示提示。

实现参考 [IINA 与 mpv 的一手代码](research/display-sleep-2026-10-26.md)，没有改动系统亮度、系统休眠超时或用户媒体库。

## 验证证据

旧实现先运行相同本地AVPlayer测试：13项中9项通过，4项保活目标检查失败；旧偏好序列化的2个新字段断言也按预期失败。最终实现扩展开关和析构场景后，19项系统检查全部通过。

| --- | --- | --- |
| 核心测试 | 161项/20套件通过 | 含旧偏好默认开启、关闭选择存储和重载 |
| 显示器保活 | 19/19通过 | 真实AVPlayer、本机IOPM进程断言；含4个媒体就绪条件检查 |
| 播放稳定性 | 15/15通过 | 原有暂停/故障恢复/连续定位/替换片源回归 |
| Release应用 | 构建、签名通过 | 0.3.8/build20；安装至dist/澄幕.app |
| ZIP | CRC、解压签名、可执行文件一致通过 | Apple Silicon安装包 |

系统检查筛选当前PID、`PreventUserIdleDisplaySleep`、名称`Chengmu video playback`及有效level：播放有一份，切换模式/拖动保持一份；关开关、暂停、片尾、坏文件和对象析构后没有遗留请求。暂停后的延迟回调不会重新占用。结束检查后 `pmset -g assertions` 的显示器空闲阻止计数为0。

“缓冲”专项是本地播放期间注入stalled通知，未将其称为真实网络断流。睡眠定时沿用现有到期调用pause的路径；本轮没有等待15分钟执行一次完整定时。没有修改显示器超时，也未做长时间实际屏幕亮度/锁屏观察；自动亮度或系统主动锁屏不在此次物理验收范围。
