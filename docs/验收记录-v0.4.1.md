# 澄幕 v0.4.1 / build24

日期：2026-10-26。以v0.4.0/build23为起点，对标公开需求后完成搜索、字幕与观看记录增量。

## 调研与取舍

对比IINA、mpv、Swiftfin、Stremio的公开文档、代码和议题，依据见[GitHub对标](research/player-benchmark-2026-10-26.md)。小红书实际搜索要求登录，X转到登录流程，Instagram为登录页；未读取其帖子。补充读取3个Reddit原帖，仅作为历史定性线索，没有统计代表性，也不能判定竞品当前仍有旧缺陷。见[社交记录](research/player-social-feedback-2026-10-26.md)。

本轮未更换播放引擎，未复制平台客户端代码。字幕时间轴跳转、播放队列、画中画和跨片字幕语言偏好仍在后续计划中。

## 行为变化

- 搜索使用已提交查询排序，编辑输入框不改变旧结果顺序或标题。匹配片名、明确季数优先，显式搜索解说/预告仍保留意图。分类保守匹配，未分类内容不消失；来源/年份/类别作用于同一来源行，保留组ID。不会仅凭片名认证内容身份。
- 来源裁剪曾导致未知年份待看记录失去匹配证据：新增3项失败用例后，待看查找完整组作身份匹配；播放仍使用筛选后的来源。审阅复查未发现新增问题。
- 字幕显示开关独立于移除轨道，隐藏保留cues/外挂/偏移。字号18–36、背景和上移0–120使用独立偏好键保存，非有限值回退默认。暂停导入立即刷新；失败导入保留原字幕；同片重试按轨道名称、语言与媒体类型匹配，缺失/歧义时不复用数组索引。新片清除文件、选轨与偏移，保留样式。ASS仅提取文本。
- 历史有效时长播放到95%判为完成；未知或非有限值不判完成。先选择最新集/全部剧集再筛选未完成，避免最新集完成后旧集反复冒出。全部记录仍可看，重新观看从0开始，不通过筛选删除数据。
