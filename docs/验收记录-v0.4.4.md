# v0.4.4 验证记录

- Swift 核心测试：194 项、26 个套件通过。
- 预览：生成的本地 MP4、旋转 MP4 和本机 HTTP HLS，通过实际 AVFoundation 取帧检查；重复相同位置的事件在旧代码下触发断言，修复后通过。并未验证所有远程来源。
- 切源：12 项 AppModel/AVPlayer 测试通过；使用注入的异步检查模拟首条慢、第二条快，旧代码未及时切换，新代码通过；不代表实际外网性能。
- 播放稳定性：22 项通过，包含本机 HTTP 连接等待、无数据时速度未知、更换影片后清除状态；部分中断事件由测试注入，不代表真实外网长期播放。
- 速度是 AVPlayer 访问日志提供的累计观测吞吐，不是即时流量；缓冲进度以连续已缓存时长相对于 12 秒目标显示，不是文件下载百分比。
- 实际媒体请求仍由 AVPlayer 使用系统网络设置；本版没有实现媒体直连优先，也未验证特定 VPN 或代理环境。原片源、网络或视频编码仍可能导致卡顿和预览不可用。

结构化结果：[预览](validation/v0.4.4/seek-preview.json)、[切源](validation/v0.4.4/episode-switch.json)、[播放稳定性](validation/v0.4.4/playback-stability.json)。
