# v0.4.5 验证记录

- 核心测试：225 项、32 个套件通过。
- 直连：本机 HTTP 与真实 AVPlayer 回归 29 项（含直连速度采样），包括普通文件播放/跳转、预览、401/Cookie/异常 Range 回退、取消释放、60 次连续和 5 次间隔切换。另在本机系统 HTTP/HTTPS/SOCKS 代理开启时对公开 MP4 进行了短时播放和跳转；不证明 VPN、DNS、大陆网络或长片稳定性。
- 媒体读取：11 项本机 HTTP 检查，包含 HEAD 405、无后缀 MP4/HLS、Range 被忽略、无效页面、超时与取消；仅验证前缀或清单，不验证完整播放。
- 预览：本地 MP4、旋转视频、普通及无后缀 HLS；确认类型晚到后重试当前悬停。远程链接和所有编码未验证。
- 来源与界面：29 项 AppModel/SwiftUI 模型及位图检查；13 项选集/换源检查，电影案例为本地媒体和注入目录，不是完整网络影视播放或人工验收。
- 新开放目录分别通过一次本机搜索/详情检查，Archive 读取媒体前 1024 字节，Commons 的一个样本取得首帧；许可由上传者声明，未独立验证权利、完整播放或大陆可达性。
- 发现并修复直连快速切源压力测试中的资源请求未完成问题。另一并行稳定性测试曾因在异步 seek 完成前断言而失败；增加真实位置等待条件后，串行稳定性检查通过。
- 排序只比较已经找到并测量到的来源；暂停自动检查、超过队列容量、服务器拒绝 HEAD 或网络不可达时，部分候选仍为未知。播放中的来源搜索保留已有检测结果，不另行抢占视频带宽。
