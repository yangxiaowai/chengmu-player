# v0.4.7 预览验证记录

本轮针对悬浮预览持续加载或过早不可用进行定位。受控本地 HLS 复现了两种旧版问题：目标分片延迟 3 秒时，2 秒定位超时过早结束；悬浮时间在相近位置持续抖动时，请求不断重启。另一个无后缀 HLS 样本中的视频轨出现在播放器项目上，而资产本身返回空的轨道列表。

- **预览解码**：使用本地 MP4、旋转视频、普通 HLS、慢清单、慢分片和无后缀 HLS 的受控样本，验证目标时间取帧、网络等待、失败后的有限退出、取消与切换隔离。旧版失败与修复后的通过均有本地日志。
- **画面与主播放**：23 项本地检查通过，使用不同时间段呈现不同颜色的合成视频，检查预览帧内容、持续悬浮、无后缀 MP4、旋转画面和主播放器时间轴；还检查生产 HLS 中继的预览取消不会触发错误回退。素材为本机生成，不代表用户片源网络表现。
- **进度条交互**：21 项检查通过，对真实 AppKit 控件使用合成鼠标事件检查悬浮抖动、停稳后的实际位置、移动、点击、拖动、尺寸和时长变化及过期回调取消。该检查未代替用户实际鼠标操作验收。
- **公开网络样本**：一次 Apple 官方 Bip Bop HLS 样本经生产中继请求 15 秒，取得 15 秒的预览帧，约 1.44 秒完成，主播放继续推进。此结果是一次测试，不代表用户实际片源或长时间网络状况。
- **回归**：227 项核心测试和 33 项原有文件/HLS 直连控制器检查通过，包含原有文件直连资源的预览。

测试未证明任意外部影片的预览均可用。需要定位支持的媒体服务器、可解码的内容和可用网络；片源响应过慢或不支持定位时仍可能显示预览不可用。
